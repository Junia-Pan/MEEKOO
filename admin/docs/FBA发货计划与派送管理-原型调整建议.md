# FBA发货计划与派送管理 — 原型调整建议

> 依据 `FBA派送管理需求文档.md`（**V1.1**）与当前 HTML/PDA 原型对照整理，供下一轮改原型使用。

---

## 1. 总原则

| 原则 | 说明 |
|------|------|
| 状态分层 | **装车单**止于「已发车」；「运输中 / 已签收 / 已退仓」等在 **BOL**（**自发车起派送生效**） |
| 列表语义 | 派送管理 Tab、筛选、行操作按 **BOL**（或 BOL+装车单展示），勿把运输中标在装车单上 |
| 终态过滤 | 派送列表默认隐藏 **已退仓** BOL；备货减货**无「已作废」**，痕迹在计划/装车单日志 |
| 备货减货 | 改计划/装车范围，解除预备 BOL；**不在派送管理展示已作废** |
| 端分工 | 员工端：指令、计划绑定、发车（有权限）；PDA：备货/装车/发车/执行 |

---

## 2. 员工端

### 2.1 `fba-plan-management.html`（计划单管理）

| 项 | 现状/风险 | 建议 |
|----|-----------|------|
| 计划状态 | 含已装车、已发车等 | 计划单保留待安排备货、待装车、已取消等；**不宜**长期停留在已发车（发车后看 BOL） |
| 减货 | 原型可能未体现 | PDA/员工端：计划剔货、解除预备 BOL、操作日志；**勿**在派送管理标「已作废」；剔光回待安排备货 |
| 重新排货 | — | 提供「待关联计划的新 BOL」或计划详情内「新增 BOL 行 / 新建计划」入口 |

### 2.2 `fba-load-management.html`（装车单管理）

| 项 | 现状/风险 | 建议 |
|----|-----------|------|
| 装车单状态 | 含已发车 | 装车单：**待装车 → 已装车 → 已发车** 即可，勿再加运输中/已签收 |
| 子表计划/BOL | 计划行有已发车等 | 子表 BOL 列展示 **BOL 状态**（运输中、已签收、已退仓） |
| 发车 | 调度「已发车」弹窗 | 文案改为「仓库或员工端，有权限即可」；若 PDA 已发车，员工端只读或补录信息 |
| 发车后 | 装车单仍显示运输中 | 已发车装车单：总状态固定已发车；运输进度看 BOL 列表 |

### 2.3 `fba-outbound-shipping-management.html`（FBA 派送管理）

| 项 | 现状/风险 | 建议 |
|----|-----------|------|
| 列表 Tab | 已装车/运输中/已签收等 | 明确为 **BOL** 维度；**去掉「已作废」Tab**（V1.1）；按 BOL 状态筛选 |
| 行状态 `loadStatus` | 演示用装车单级状态 | 改为 **BOL 状态** 字段驱动 Tab 与按钮 |
| 已发车按钮 | 仅「已装车」可发车 | 与装车单管理一致；支持「任一端已发车则不可重复」 |
| 整车退仓 | 演示为「整车退仓处理中」 | 与 PDA 对齐：执行后装车单+全部 BOL → **已装车**；文案说明虚拟库位、不回在库 |
| 单项退仓 | 写 rejectReason 等 | 增加 **BOL 状态 = 已退仓**；货件在库在货件模块体现 |
| 货件补录 | 写 remark | 区分文案：**在途补录**，非备货加货 |

## 3. PDA

### 3.1 `outbound-pick.html`（出库备货）

| 项 | 建议 |
|----|------|
| 加货 | 已有；提交后生成新 BOL + 新计划单 + 加货标识，与 PRD 一致 |
| 减货 | 已有减货确认；执行后：**计划剔货**、**解除/删除预备 BOL**、写日志；剔光则待安排备货+解除装车单（员工端同步） |
| 发车 | 若有发车入口：有权限即可提交；成功后装车单已发车、BOL 运输中 |

### 3.2 `return.html`（整车退仓）

| 项 | 现状 | 建议 |
|----|------|------|
| 说明文案 | 不回在库 | **保留**，与 PRD 一致 |
| 库位字段 | 必填库位 | 文案改为 **退仓虚拟库位（仅留痕）**，避免理解成真实上架 |
| 提交结果 | 装车单已装车 | 同步：**该单全部 BOL → 已装车** |

### 3.3 `self-return.html`（单项退仓）

| 项 | 建议 |
|----|------|
| 提交后 | 提示 BOL **已退仓**；货件在库；库位走「入库上架」 |
| 计划单 | **不要求** PDA 选择计划单；重新排货在员工端 |

### 3.4 `wms-pda.html`（入口）

| 项 | 建议 |
|----|------|
| 整车退仓描述 | 「已装车货物整批退库」易误解 | 改为「登记虚拟库位，装车单/BOL 回已装车，货件不回在库」 |

---

## 4. 建议优先改动的 5 处（P0）

1. **派送管理列表**：状态字段与 Tab 改为 BOL 维度。  
2. **装车单管理**：装车单状态去掉运输中/已签收；子表展示 BOL 状态。  
3. **整车退仓**：员工端 + PDA 统一为虚拟库位 + 装车单/BOL 已装车。  
4. **单项退仓**：增加 BOL「已退仓」展示；列表过滤终态 BOL。  
5. **发车**：双端有权限即可 + 防重复提交提示。

---

## 5. 可选（P1）

- 员工端「待关联计划的新 BOL」队列（服务单项退仓后重新排货）。  
- 计划单详情：历史 BOL / 当前有效 BOL 分开展示。  
- 操作日志统一记：端类型（员工端/PDA）、对象（计划/装车单/BOL）。
