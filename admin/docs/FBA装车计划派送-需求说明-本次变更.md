- 整车退仓：同装车单全部 BOL 处理，完成后回**已装车**，货件**不回**排货总览。
- 装车单状态止于已发车；运输中 / 签收 / 退仓在 BOL 层。
- 货件补录、POD、已发车等原有门禁不变。

## 2. 核心逻辑（先看这个）

### 2.1 三页分工

```
计划单管理          装车单管理              FBA 派送管理
─────────          ──────────              ──────────────
创建计划            挂计划、排送仓顺序       已装车后的 BOL 作业
安排备货 ──生成BOL→  看 BOL 号、导出备货单   发车 / POD / 改 BOL / 退仓
```

### 2.2 BOL 什么时候出现、谁能看见

| 时机 | BOL 状态 | 装车单页 | FBA 派送页 |
|------|----------|----------|------------|
| 安排备货成功 | 待装车 | ✅ 子表有 BOL 号 | ❌ 不出现 |
| 装车单 → 已装车 | 已装车 | ✅ | ✅ 进入列表 |
| 已发车 | 运输中 | ✅ | ✅ |
| 上传 POD | 已签收 | ✅ | ✅ |
| 装车前移除计划 | 已作废 | ❌ 不再展示有效 BOL | ❌ |

**规则要点**

- BOL 在**安排备货**时按「装车单 + 计划单」自动生成；编号规则为 **FBA Code + 装车日期(yyyyMMdd) + 3位序号**，序号按**装车日期**全局递增（不按 FBA Code 各自从 001 起）。
- 装车前从装车单**移除计划** → 对应 BOL **作废**。
- **已装车**后不能再往装车单加/减计划。

### 2.3 送仓顺序（多计划装车单）

```
计划数 ≥ 2  →  必须先保存送仓顺序  →  才能安排备货 / 导出备货单
计划数 < 2  →  送仓顺序区隐藏，显示「-」

展示规则：按计划顺序拼接 FBA Code，用「-」连接，不去重
示例：两个 ONT8 计划  →  显示 ONT8-ONT8（不是 ONT8）
```

调整方式：修改装车单弹窗内拖拽排序（去掉 ↑↓ 按钮）。

### 2.4 单项退仓 vs 整车退仓

> 单项退仓完整说明见 **`FBA单项退仓-需求说明.md`**。

| | 整车退仓 | 单项退仓（本次新逻辑） |
|---|----------|------------------------|
| 粒度 | 同装车单全部 BOL | 当前 BOL 下按**柜号** |
| 1 柜 / 多柜全选 | — | **原 BOL** 整单 → 退仓待执行（**不生成 `-N`**） |
| 多柜部分选 | — | 原 BOL 仍运输中 + 新建 **`{原BOL}-N`** |
| 退仓完成 | 装车单 + 全部 BOL → **已装车** | 删行；货回**排货总览·在仓未排**；装车单不变 |
| 撤销退仓 | 同单全部整车 BOL 回运输中 | 整 BOL 回运输中；或删 `-N` 并柜回原 BOL |

## 3. 分页面需求

### 3.1 装车单管理

#### 变更点

| 项 | 变更内容 |
|----|----------|
| 子表列 | 新增 **BOL 号**；**柜号**、**系统单号**拆成两列（多值逗号展示） |
| 送仓顺序 | 列表与修改弹窗预览：**不去重**；≥2 计划才显示排序区 |
| 排序交互 | 仅拖拽，移除 ↑↓ |
| 导出备货单 | **新增**：工具栏「更多」、行「更多」；导出文件 `{装车单号}.xlsx` |
| 导出校验 | ≥2 计划且未保存顺序 → 阻断；工具栏提示带装车单号，行内不带 |
| 已装车 | **添加计划 / 移出计划** 禁用 |
| 已装车动作 | 确认已装车时，下属 BOL **同步进入 FBA 派送列表** |

#### 送仓顺序保存

- 入口：修改装车单 → 送仓顺序区域（≥2 计划时显示）。
- 保存后写 `seqSet=true`，列表「送仓顺序」列展示已保存结果。

---

### 3.2 计划单管理

#### 变更点

| 项 | 变更内容 |
|----|----------|
| ISA 来源 | 创建计划、修改计划增加下拉：**自有/外部 × Amazon/Walmart/TK**（6 项） |
| 列表 | 新增 **ISA 来源** 列 |
| 安排备货 | 若目标装车单 ≥2 计划（含本次待安排）且**未设送仓顺序** → 阻断并提示去装车单设置 |
| 安排备货成功 | 计划 → 待装车，关联装车单，并**生成 BOL（待装车）** |
| 已发车计划 | ISA 相关字段**只读**；后续 ISA 变更在 FBA 派送「修改 BOL」 |

#### ISA 来源枚举

自有Amazon、外部Amazon、自有Walmart、外部Walmart、自有TK、外部TK

### 3.3 FBA 派送管理

#### 变更点

| 项 | 变更内容 |
|----|----------|
| 列表维度 | 一行 = **一个 BOL**（装车单 + 计划）；仅展示已进派送阶段的 BOL |
| 新增列 | **ISA 时间**、**ISA 来源** |
| 柜号 | 一个 BOL 多柜时**逗号分隔**；列表顺序跟装车单送仓顺序 |
| 修改 BOL | **新增**；入口：行「更多」、详情页；**已装车 / 运输中** |
| 单项退仓 | **重做**：按柜退仓；详见 `FBA单项退仓-需求说明.md` |

#### 修改 BOL

| 字段 | 说明 |
|------|------|
| ISA | 必填 |
| ISA 时间 | 必填，日期（预约送达时间，以 ISA 为准） |
| ISA 供应商 | 选填 |
| ISA 来源 | 选填，枚举同计划单 |
| 变更凭证 | 选填，单文件 |
| ISA 变更原因 | 必填 |

保存后：**6 项以 BOL 为准覆盖计划单**（计划已装车/已发车后亦在此维护 ISA）。

#### 单项退仓（摘要）

完整需求见 **`admin/docs/FBA单项退仓-需求说明.md`**。

1. 选中 **运输中** BOL → 单项退仓弹窗。
2. 柜号：1 柜默认勾选置灰；≥2 柜复选框 + 全选/取消 + 预览。
3. **通知仓库退仓**：整 BOL（1 柜/全选）→ 原 BOL 退仓待执行；部分选 → `{原BOL}-N` + 原 BOL 仍运输中。
4. **确认退仓完成** / **撤销退仓**：见专项文档第 5、6 节。

## 4. 关键业务规则表

| 场景 | 规则 |
|------|------|
| BOL 与计划关系 | 1 装车单 + 1 计划单 = 1 BOL |
| BOL 生成 | 安排备货成功 |
| BOL 作废 | 已装车前从装车单移除计划 |
| BOL 进派送列表 | 装车单标记已装车 |
| 送仓顺序必填 | 装车单下计划 ≥2，且操作 = 安排备货 或 导出备货单 |
| 送仓顺序展示 | 计划顺序拼接 FBA，`-` 连接，不去重 |
| 已装车 | 不可加/减计划 |
| 修改 BOL | 仅 BOL=运输中；字段同步计划 |
| 单项退仓 · 整 BOL | 1 柜或全选；原 BOL 退仓待执行，不拆分 |
| 单项退仓 · 部分 | 生成 `{原BOL}-N`；原 BOL 仍运输中 |
| 单项退仓完成 | 删行；货件 → 排货总览·在仓未排；装车单不变 |
| 单项退仓撤销 | 整 BOL 回运输中；或删 `-N` 并柜回原 BOL |
| 整车退仓完成 | 装车单 + 全部 BOL → 已装车（不变） |

## 5. 验收要点

| # | 验收项 | 预期 |
|---|--------|------|
| 1 | 安排备货 | 生成 BOL；装车单子表可见；派送列表不可见 |
| 2 | 未排顺序的多计划装车单 | 安排备货、导出备货单均阻断 |
| 3 | 送仓顺序展示 | 两同 FBA 计划显示 `ONT8-ONT8` |
| 4 | 已装车 | 不可加/减计划；BOL 出现在 FBA 派送列表 |
| 5 | 移除计划（装车前） | 对应 BOL 作废 |
| 6 | 导出备货单 | 文件名为装车单号 |
| 7 | 计划 ISA 来源 | 创建/修改/列表可见 |
| 8 | 修改 BOL | 仅运输中；保存后提示已同步计划 |
| 9 | 单项退仓 2 柜选 1 | 生成 `-1`；原 BOL 剩 1 柜仍运输中 |
| 10 | 单项退仓 1 柜 / 2 柜全选 | 原 BOL 退仓待执行，无 `-N` |
| 11 | 单项退仓完成 / 撤销 | 见 `FBA单项退仓-需求说明.md` 验收表 |
| 12 | 整车退仓 | 行为与改前一致，回已装车 |
