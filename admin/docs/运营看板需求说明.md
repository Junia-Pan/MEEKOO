# 首页（运营看板）— 需求说明

## 1. 文档说明

约定员工端「首页」统计口径与展示规则。侧栏入口为「首页」，登录后默认进入本页。本期只读统计，不做下钻跳转。

### 1.2 名词解释

| 名词 | 定义 |
|------|------|
| 预计到港 | 按 ETA 统计的预计到港量（前瞻） |
| 实际到仓 | 已实际到仓量（历史） |
| 实际拆柜 | 已实际拆柜量（历史） |
| 下单 | 下单量（历史） |
| 柜数 / 方数 / 重量(LB) | 统计指标：柜、CBM、磅 |
| 船司 / 客户 / Move Type | 走势拆解维度；表头首列随切换显示对应名称 |
| 本周 | 自然周：周一～周日 |
| 占比 | 行「区间合计」÷ 各行区间合计之和 |
| 相对本周 / 相对今天 | 仅预计到港：其余周期均值相对基准期（本周或今天）的涨跌 |
| 环比 | 仅实际类：近月为本周相对上周；近周为今天相对昨天 |

---

## 2. 目标

运营人员一眼看清今日四类柜量，以及按船司 / 客户 / Move Type 的近月、近周走势与结构占比。

**本期不做：** 点击数字跳转明细、自定义日期、图表主视图。

---

## 3. 页面结构

1. **今日概览**：预计到港、实际到仓、实际拆柜、下单四张只读卡；主数字为今日柜数；副文案为对比提示；支持刷新与更新时间（精确到秒）。
2. **近期走势**：全局时间范围（近 1 月 / 近 1 周）+ 四张独立走势卡。

界面以现有原型为准。

---

## 4. 核心业务规则

### 4.1 四类场景

| 场景 | 时间方向 | 走势对比列 |
|------|----------|------------|
| 预计到港 | 前瞻 | 近月：相对本周；近周：相对今天 |
| 实际到仓 | 历史 | 环比 |
| 实际拆柜 | 历史 | 环比 |
| 下单 | 历史 | 环比 |

四卡相互独立：各有维度（按船司 / 按客户 / 按 Move Type）与指标（柜数 / 方数 / 重量(LB)）。

### 4.2 今日概览对比

| 卡片 | 副文案口径 |
|------|------------|
| 预计到港 | 较本周日均 N 柜 + 涨跌（今日相对本周合计÷7） |
| 实际到仓 / 实际拆柜 / 下单 | 较昨日 N 柜 + 涨跌 |

### 4.3 时间范围

| 范围 | 默认 | 预计到港列 | 实际类列 |
|------|------|------------|----------|
| 近 1 月 | 是 | 本周 + 后 3 周（共 4 周） | 本周 + 上周 + 前 2 周 + 前 3 周（共 4 周） |
| 近 1 周 | 否 | 今天起往后 7 天（含今天） | 今天起往前 7 天（含今天） |

- 近月周边界为周一～周日。
- 无自定义日期。

### 4.4 指标与维度

| 维度 | 可选指标 | 默认 | 说明 |
|------|----------|------|------|
| 按船司 | 柜数、方数、重量(LB) | 船司 + 柜数 | 最多 20 行（含「其他」） |
| 按客户 | 柜数、方数、重量(LB) | — | 同上 |
| 按 Move Type | 方数、重量(LB) | — | 同上；**柜数置灰保留、不可选**（避免重复计柜） |

切到 Move Type 时若当前为柜数，自动切到方数；柜数按钮仍显示但置灰，避免布局跳动。

### 4.5 表格列与计算

| 列 | 规则 |
|----|------|
| 首列 | 随维度切换显示「船司 / 客户 / Move Type」，不用「维度」；超过 20 个时保留前 19 +「其他（N 个）」 |
| 各周期列 | 对应周/日指标值；今天列可加粗；纯展示，不可点击 |
| 合计 | 当前可见各周期列之和 |
| 占比 | 行合计 ÷ 各行合计之和；仅船司、客户展示；Move Type 不展示 |
| 相对本周 / 相对今天 | 仅预计到港。小柱图：各周期走势（深蓝柱为基准期）。百分比：其余周期均值相对基准期。公式：周均 = 后 3 周之和÷3；涨跌% = (周均−本周)÷本周×100%（近周同理，基准为今天，其余 6 天日均） |
| 环比 | 仅实际类。小柱图同上。百分比：近月 = (本周−上周)÷上周；近周 = (今天−昨天)÷昨天 |
| 合计行 | 汇总各周期、合计、占比（100%）；**走势对比列留空** |

涨跌：上涨红、下跌绿；变化不足 0.5% 为持平；基准为 0 且当期有量显示「新增」。  
走势对比列表头左侧有说明 icon，悬停展示规则。

### 4.6 柜数口径

- 今日概览柜数、按船司/客户看柜数：按船司柜数加总，避免 Move Type 重复计柜。
- 方数、重量(LB) 可按各维度直接汇总。

### 4.7 展示约束

- 表体固定约 5 行可视高度；不足留白，超过内部滚动；表头吸顶、合计吸底。
- 每张走势卡：标题行右侧为维度切换 + 指标切换（同一行）。

---

## 5. 界面要点

以现有原型「首页」为准：

- 侧栏「首页」；登录默认进入本页。
- 近期走势仅「近 1 月」「近 1 周」，近 1 月在前且默认选中。
- 指标文案：柜数、方数、重量(LB)。
- 数字只统计、不跳转明细。

---

## 6. 验收要点

1. 近 1 月 / 近 1 周列集合与 4.3 一致；预计到港与实际类时间方向不错用。
2. 今日概览：预计到港较本周日均；其余三卡较昨日。
3. Move Type 下柜数置灰不可点；从柜数切入时自动切到方数且布局不跳动。
4. 首列表头随维度切换为船司/客户/Move Type；各维度最多 20 行（含其他）；占比合计 100%。
5. 预计到港为相对本周/今天；实际类为环比；合计行无走势图。
6. 表体 5 行高内滚动，合计可见；点击数值不跳转。
7. 侧栏与登录落地为首页。
