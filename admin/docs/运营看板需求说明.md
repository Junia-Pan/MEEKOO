# 首页（运营看板）— 需求说明

## 1. 文档说明

约定员工端「首页」的统计口径与展示规则（原运营看板）：今日四类柜量概览，以及近一个月 / 近一周的走势拆解。本期为只读统计，不做下钻跳转。侧栏入口名为「首页」，登录后默认进入本页。

### 1.2 名词解释

| 名词 | 定义 |
|------|------|
| 预计到港 | 按 ETA 统计的预计到港量（前瞻） |
| 实际到仓 | 已实际到仓量（历史） |
| 实际拆柜 | 已实际拆柜量（历史） |
| 下单 | 下单量（历史） |
| 柜数 / 方数 / 重量 | 统计指标：柜、CBM、LB |
| 船司 / 客户 / Move Type | 走势拆解维度 |
| 本周 | 自然周：周一 00:00～周日 23:59:59 |
| 占比 | 当前行「区间合计」占全部行区间合计之和的比例 |
| 相对本周 | 仅预计到港：其余周期均值相对本周的涨跌 |
| 环比 | 仅实际类：本周相对上周（或今天相对昨天）的涨跌 |

---

## 2. 目标

运营人员一眼看清：今天四类业务量，以及按船司 / 客户 / Move Type 的近月、近周走势与结构占比。

**本期不做：** 点击数字跳转明细、自定义日期、图表主视图。

---

## 3. 页面结构

1. **今日概览**：四张只读卡——预计到港、实际到仓、实际拆柜、下单；展示今日柜数及对比提示（预计到港较本周日均，其余较昨日）；支持刷新与更新时间（精确到秒）。
2. **近期走势**：全局时间范围（默认近 1 月，其次近 1 周）+ 四张独立走势卡（预计到港 / 实际到仓 / 实际拆柜 / 下单）。

界面细节以现有原型为准。

---

## 4. 核心业务规则

### 4.1 四类场景

| 场景 | 时间方向 | 走势对比列 |
|------|----------|------------|
| 预计到港 | 前瞻 | 相对本周 / 相对今天 |
| 实际到仓 | 历史 | 环比 |
| 实际拆柜 | 历史 | 环比 |
| 下单 | 历史 | 环比 |

四卡相互独立：每卡自有指标（柜数 / 方数 / 重量）与维度（船司 / 客户 / Move Type），互不影响。

### 4.2 时间范围

| 范围 | 默认 | 预计到港列 | 实际类列 |
|------|------|------------|----------|
| 近 1 月 | 是 | 本周 + 后 3 周（共 4 周） | 本周 + 上周 + 前 2 周 + 前 3 周（共 4 周） |
| 近 1 周 | 否 | 今天起往后 7 天（含今天） | 今天起往前 7 天（含今天） |

- 周边界固定为 **周一～周日**。
- 近 1 周不做自定义区间。

### 4.3 指标与维度

| 维度 | 可选指标 | 默认 | 说明 |
|------|----------|------|------|
| 按船司 | 柜数、方数、重量 | 船司 + 柜数 | 各维度均最多 20 行；超出按区间合计并入「其他」 |
| 按客户 | 柜数、方数、重量 | — | 同上 |
| 按 Move Type | 方数、重量 | — | 同上；**柜数置灰不可选**（避免重复计柜） |

切换到 Move Type 时若当前为柜数，自动落到方数。

### 4.4 表格列与计算

| 列 | 规则 |
|----|------|
| 首列 | 随右上维度切换显示「船司 / 客户 / Move Type」；超过 20 个时保留前 19 +「其他（N 个）」，合计最多 20 行 |
| 各周期列 | 该维度在该周或该日的指标值；今日列可加粗；**纯展示，不可点击** |
| 合计 | 当前可见各周期列之和 |
| 占比 | 行合计 ÷ 各行合计之和；仅船司、客户展示；Move Type 不展示占比 |
| 相对本周 / 相对今天 | 仅预计到港。柱图为各周期走势（深蓝柱为基准期）；百分比 = 其余周期均值相对基准期。近月基准=本周，近周基准=今天 |
| 环比 | 仅实际类。柱图同上；百分比：近月=本周÷上周−1，近周=今天÷昨天−1 |
| 合计行 | 对各周期与合计、占比（100%）汇总；**走势对比列留空**（不画柱、不算涨跌） |

涨跌展示：上涨红、下跌绿；变化不足 0.5% 视为持平；基准为 0 且当期有量显示「新增」。

### 4.5 柜数口径

- 今日概览柜数、以及按船司/客户看柜数：按 **船司维度柜数加总**，避免 Move Type 拆分导致重复计柜。
- 方数、重量可按各维度直接汇总。

### 4.6 展示约束

- 表体固定约 **5 行**可视高度；不足 5 行留白垫高，超过则内部滚动。
- 表头吸顶，合计行吸底。
- 走势对比列表头左侧提供说明 icon，悬停展示该列计算规则。

---

## 5. 界面要点

以现有原型「首页」为准，补充约束如下：

- 近期走势时间切换：仅「近 1 月」「近 1 周」，近 1 月在前且默认选中。
- 每张走势卡自有指标与维度切换；数字只统计、不跳转明细。

---

## 6. 验收要点

1. 近 1 月 / 近 1 周下列集合与第 4.2 节一致；预计到港与实际类方向相反且不错用。
2. Move Type 无柜数；从柜数切到 Move Type 时指标自动变为方数。
3. 各维度最多 20 行（含「其他」）；占比加总为 100%。
4. 预计到港走「相对本周/今天」；实际类走「环比」；合计行无走势图。
5. 多行时表体 5 行高内滚动，合计始终可见；点击数值不跳转。
