# 运营看板需求说明

## 1. 数据来源

提拆派计划 —— 运输方式为海运（排除「已取消」状态）。

---

## 2. 名词解释

| 名词 | 定义 |
|------|------|
| 预计到港 | 按 ETA（预计到港日）统计；时间方向为前瞻 |
| 实际到仓 | 已实际到仓库的量；时间方向为历史 |
| 实际拆柜 | 已完成拆柜的量（状态为「已拆柜」，不论是否生成拆柜报告）；时间方向为历史 |
| 下单 | 客户下单量（排除「已取消」）；时间方向为历史 |
| 柜数 | 集装箱个数（整数） |
| 方数 | 体积 CBM（保留 3 位小数） |
| 重量(LB) | 磅（保留 2 位小数）；界面文案固定为「重量(LB)」 |
| 本周 | 周一～周日（含今天的自然周） |
| 相对本周 / 相对今天 | 仅预计到港：其余周期均值相对基准期（本周或今天） |
| 环比 | 仅实际到仓 / 实际拆柜 / 下单：本周相对上周，或今天相对昨天 |
| 占比 | 行合计 ÷ 各行合计之和，整数 %，可见行之和 = 100% |

---

## 3. 页面结构

1. **今日概览**：预计到港 / 实际到仓 / 实际拆柜 / 下单四张只读卡（今日柜数 + 对比文案）；刷新 + 更新时间（精确到秒）。
2. **近期走势**：全局范围「近 1 月」（默认）/「近 1 周」+ 四张独立走势表（维度、指标各自独立）。

侧栏入口为「首页」，登录后默认进入本页。本期只读，不做点击数字下钻、自定义日期、图表主视图。

---

## 4. 今日概览

- 主数字 = 该场景今日柜数（按船司汇总，避免重复计柜），单位「柜」。
- **预计到港**：`较本周日均 {round(本周柜数/7)} 柜 {涨跌}`；涨跌基准用未取整的 `本周柜数/7`。
- **实际到仓 / 实际拆柜 / 下单**：`较昨日 {昨日柜数} 柜 {涨跌}`。
- **刷新**：重算全页并更新时间戳；不重置范围 / 维度 / 指标。

涨跌文案规则见第 6 节。

---

## 5. 四个走势表

四张表分别对应：预计到港、实际到仓、实际拆柜、下单。时间方向与第 2 节名词一致（预计到港前瞻，其余历史），**禁止混用列方向或对比口径**。

### 5.1 共用规则

- **范围**：全局切换「近 1 月」（默认、靠左）/「近 1 周」；切范围时各卡已选维度、指标保持不变。
- **维度**：按船司 / 按客户 / 按 Move Type（每张卡独立）。
- **指标**：柜数 / 方数 / 重量(LB)。按 Move Type 时柜数按钮保留但置灰禁用（避免多 Move Type 重复计柜）；悬停提示「Move Type 不支持按柜数统计」；若当前为柜数则自动切到方数。
- **默认**：每张卡初始为按船司 + 柜数。
- **表高**：约 5 行可视；不足留白，超出内滚；表头吸顶、合计吸底。
- **交互**：数字不可点击跳转；切维度 / 指标 / 范围只改展示。

### 5.2 列（从左到右）

名称列 → 各周期列 → 合计 → 占比 → 走势对比。

| 列 | 规则 |
|----|------|
| 名称列 | 表头随维度写「船司 / 客户 / Move Type」，禁止写「维度」 |
| 周期列 | 见 5.3；列头近月为 `标签(M/D-M/D)`，近周为 `标签(M/D)`；基准列「本周 / 今天」表头与数值加粗 |
| 合计 | 本行各周期列之和 |
| 占比 | 船司 / 客户 / Move Type 均有。行合计 ÷ 各行合计之和，整数 %（先向下取整，余数按小数从大到小补 1）；可见行之和 = 100% |
| 走势对比 | 小柱图 + 涨跌文案；**合计行此列留空** |

卡下副文案为统计区间 `yyyy-mm-dd ~ yyyy-mm-dd`（早→晚）。

**行：**

1. 按合计降序；相同比最左周期列；再相同按名称。
2. 最多 20 行：超过则保留前 19，其余合并为「其他」+ `{N} 个`（各列求和），再重算占比。
3. 表底「合计」行：汇总各周期、合计、占比（100%）；走势对比留空。
4. 无数据：提示「暂无数据」，合计为 0，高度仍约 5 行。

### 5.3 周期列差在哪

| | 近 1 月（左→右，共 4 列） | 近 1 周（左→右，共 7 列） |
|--|--------------------------|---------------------------|
| 预计到港 | 本周、+1 周、+2 周、+3 周 | 今天起**往后** 7 天（含今天） |
| 实际到仓 / 实际拆柜 / 下单 | 本周、上周、前 2 周、前 3 周 | 今天起**往前** 7 天（含今天；第 2 列为昨天） |

周边界：周一～周日。无自定义日期。

### 5.4 最右「对比」差在哪

两种比法，不要混。

**预计到港 —— 后面几期的平均，比现在**

| 范围 | 列名 | 怎么算 |
|------|------|--------|
| 近 1 月 | 相对本周 | 后 3 周的平均值，和本周比 |
| 近 1 周 | 相对今天 | 其余 6 天的平均值，和今天比 |

**实际到仓 / 实际拆柜 / 下单 —— 只和紧挨着的上一期比**

| 范围 | 列名 | 怎么算 |
|------|------|--------|
| 近 1 月 | 环比 | 本周 比 上周 |
| 近 1 周 | 环比 | 今天 比 昨天 |

小柱图：本行各周期各一根柱，根数 = 周期列数；最左周期（本周 / 今天）用深蓝。表头 `i` tip 用上表原话说明小柱与百分比即可。涨跌样式见第 6 节。

---

## 6. 涨跌文案（今日概览与走势表共用）

颜色固定：**上涨红、下跌绿**；比不了或持平时用灰。

- **基准为 0**（含两边都没量）→ `—`（无法算涨跌幅；当期有量看主数字即可）
- **|涨跌幅| < 0.5%** → `持平`
- 涨跌幅 ≥ 0.5% → `↑N%`（红）
- 涨跌幅 ≤ −0.5% → `↓N%`（绿）

涨跌幅 =（当期 − 基准）÷ 基准 × 100%；`N` 为绝对值四舍五入后的整数。

---

## 7. 验收要点

1. 数据范围：提拆派海运，排除已取消。
2. 今日 KPI：预计到港较本周日均；其余较昨日；柜数按船司汇总。
3. 周期列：预计到港往后、实际类往前；近月 4 列、近周 7 列，不错用。
4. 对比：预计到港用后几期平均比现在；实际类只和上一期比。
5. Move Type：柜数置灰；从柜数切入自动切方数。
6. 首列随维度；Top19+其他；三种维度均有占比且合计 100%；合计行走势列空。
7. 表约 5 行高；数字不跳转；刷新不丢筛选状态。
8. 方数 3 位小数；重量(LB) 2 位小数；柜数整数。
