---

## 1. 背景

现阶段无法获知**每块板上有多少件**，出库登记不能再按「板上件数」累计。本次改为**按板扫码放行**，件数只保留整单总件数。

---

## 2. 核心规则

1. **按板登记**：扫描或点选板标即整板放行；混货板同样扫一次整板放行。
2. **件数只展示总件数**：不展示板上件数，不展示待提/已提件数。
3. **待提 / 已提只记板数**，且合并为一行。
4. **未扫完全部待提板**：提交后记为「部分提货」，未扫板标继续留库。
5. **未扫任何板**：不允许提交。
6. **自提凭证**：至少 1 张，最多 20 张。

---

## 3. 页面要求

界面以现有原型为准。下列为业务约束。

### 3.1 定位自提单（列表）

- 自提单号在左，自提码在右，两者同等突出。
- 展示：客户、总件数、提货（待提 X 板 / 已提 Y 板）、预约时间。

### 3.2 核对并放行

- 信息区与列表一致：客户、总件数、提货（待提 X 板 / 已提 Y 板）、预约时间；数值靠右。
- 扫板标出库。提示：「请扫描板标出库，如未全量提走将标记为部分提货。」
- 板标行只展示板标号、柜号、REF、已扫/待扫，**不展示件数**。
- 底部统计：本次实提 X 板 / 待提 Y 板。
- 部分提货须二次确认：待提 X 板、实提 Y 板；确认后变为「部分提货」。

---

## 4. 本期不包含

- 按板上件数核放出库
- 待提/已提拆分到件数
- 件数与板数的自动换算
