## 1. 背景

**留仓/扣货单**页面的数据，可理解为：建立拆柜报告之后，进入仓内待出的 **留仓** 与 **扣货** 货件（含其板标）。

现场需要：

1. 建拆柜报告时，**留仓**货件支持 **合并打板**（仅留仓与留仓合，不跨 Move Type），减少散票操作。
2. 出库时不必整组一次出完，允许在留仓/扣货单上 **按板勾选、分批出库**（例如先出一部分板，其余继续在库）。

---

## 2. 目标

1. **建立拆柜报告**：留仓支持合并打板；**只能留仓与留仓合并，禁止跨 Move Type**（不可与私卡派、自提等合在一起）。
2. **留仓/扣货单**：支持按板勾选、分批安排出库；未选出的板保持在库，可再次安排。

---

## 3. 数据范围（留仓/扣货单是什么）

| 项 | 说明 |
|----|------|
| 上游 | 提拆派计划 → **建立拆柜报告**（含打板 / 合板） |
| 本页池子 | 报告完成后，Move Type（或留仓类型）为 **留仓** 或 **扣货** 的货件及其板标；列表以 **留仓单号** 为主单号（合板组共用一号，散票一票一号） |
| 本页职责 | 查看、按合板组/货件展示、**选板安排出库**；不负责拆柜前整柜策略 |

扣货在本页仅作为「待出池中的一类货」处理出库；拆柜前如何整柜扣、Move Type 与合板冲突等，不在本文展开（见暂缓中的扣货专项）。

---

## 4. 具体方案

### 4.1 建立拆柜报告：留仓支持合并打板

| 项 | 规则 |
|----|------|
| 时机 | **建立**拆柜报告时 |
| 可合范围 | **仅 Move Type = 留仓 的货件之间**可合并打板 |
| 禁止 | **不得跨 Move Type**：留仓不可与私卡派、自提、FBA、扣货等其它类型勾选合并 |
| 操作 | 勾选多票留仓 → 合并打板；共用板数 / 板标，交互对齐现有同类型合板 |
| PDA | 打板合板适用范围增加「留仓」；合板时同样只允许同为留仓的目的地/货件合在一起 |
| 下游 | 合板组号、板标进入留仓/扣货单，按组合板展示 |

**说明**：报告里对「扣货」票的合板规则仍跟现网（扣货一般不参与合板 / 点扣货从合并组拎出）。本条只补齐 **留仓** 合板。

**验收**：建立报告时可合并多票留仓；勾选含非留仓票时不可合并并提示；PDA 同规则；留仓/扣货单能看到合板组与板标。

### 4.2 留仓/扣货单：选板分批出

| 项 | 规则 |
|----|------|
| 入口 | 留仓/扣货单（列表 / 详情）· 安排出库 |
| 对象 | 池内留仓、扣货货件下的 **在库** 板标 |
| 操作 | 选择出库方式 → **勾选本次要出的板**（可只选一部分）→ 确认 |
| 分批 | 未勾选的板仍为在库，可再次安排；同一合板组可多次出、每次不同板 |
| 结果 | 已选板变为已安排（或进入下游出库单据）；支持本地/外州私仓、自提、快递等既有出库方式（出库方式列表以现页为准，可按业务保留或拆细） |

**示例**：某合板组 20 板在库 → 先勾 10 板出本地私仓 → 剩余 10 板仍在库 → 再勾 10 板出外州私仓。

**验收**：可只出部分板；剩余板可再次安排；合板组与单票留仓/扣货均支持按板勾选。

| 位置 | 改动 |
