---

## 1. 功能定义

**单项退仓**：在 BOL **运输中**时，按**柜号**选择退仓范围，通知仓库退仓；仓库完成退仓后确认，货件回到**排货总览 · 在仓未排**。

| 项 | 说明 |
|----|------|
| 操作粒度 | BOL / 柜号（非装车单维度） |
| 与整车退仓 | 整车退仓 = 同装车单**全部 BOL**一并处理；单项退仓 = 当前 BOL 下按柜处理 |
| 装车单 / 计划单 | 单项退仓**全程不改变**装车单、计划单状态（装车单保持**已发车**） |

---

## 2. 入口与前置条件

### 2.1 入口

| 入口 | 说明 |
|------|------|
| 工具栏 | 「单项退仓」（须先勾选列表行） |
| 行操作 | 「更多 → 单项退仓」 |

### 2.2 前置条件

| 条件 | 说明 |
|------|------|
| BOL 状态 | 必须为 **运输中** |
| 不可操作 | 已装车、已签收、退仓待执行、已退仓等 |

### 2.3 列表展示

- **退仓类型**列：仅当 BOL 为 **退仓待执行** 时显示「单项退仓」；其余状态为「—」。

---

## 3. 柜号选择（交互）

弹窗内以 **「退仓单号」** 区域表格展示货件（列：柜号、系统单号、客户），首列复选框选择退仓范围；按柜数区分行为：

| 项 | 说明 |
|----|------|
| 区域标题 | **退仓单号**（非表格列名） |
| 柜号 | 每行展示，首列可勾选 |
| 系统单号 | 每行展示（取自 BOL） |
| 客户 | 每行展示（取自 BOL） |

| 原 BOL 柜数 | 标签 | 交互 | 辅助操作 |
|-------------|------|------|----------|
| **= 1** | 退仓单号 | 默认**勾选**且**置灰不可取消** | 无全选/取消；无预览行 |
| **≥ 2** | 选择退仓单号 * | 用户勾选；至少 1 柜 | 提供「全选 / 取消」；勾选后显示预览 |

### 3.1 多柜预览（实时）

| 勾选情况 | 预览文案 |
|----------|----------|
| 未勾选 | 请勾选退仓柜号（全选 = 整单退仓） |
| 全选 | 整 BOL 退仓 |
| 部分选 | 部分退仓 · 将生成 `{原BOL}-N` · 原 BOL 保留：{剩余柜号} |

> `-N` 为同一原 BOL 下递增序号（`-1`、`-2`…）；预览与确认框应展示**即将生成的实际编号**。

---

## 4. 通知仓库退仓

### 4.1 填写字段

| 字段 | 必填 | 说明 |
|------|------|------|
| 期望到仓日期 | 是 | 通知阶段 |
| 退仓原因 | 是 | 下拉 |
| 详细说明 | 是 | 文本 |
| 实际到仓时间 | 否 | 退仓完成时填 |
| 退仓凭证 | 否 | 退仓完成时上传 |

### 4.2 BOL 处理规则（核心决策表）

| 柜号选择 | 条件 | BOL 编号 | 是否新建记录 | 原 BOL | 退仓对象状态 |
|----------|------|----------|--------------|--------|--------------|
| **整 BOL 退仓** | 仅 1 柜，或多柜**全选** | **沿用原 BOL 号** | **否** | — | 原 BOL → **退仓待执行** |
| **部分退仓** | 多柜且**未全选** | **`{原BOL}-N`** | **是** | 去掉已选柜，**仍运输中** | 拆分 BOL → **退仓待执行** |

**编号规则**

- 拆分 BOL 编号：`{rootBolNo}-N`，N 从 1 递增，基于同一原 BOL 已有拆分行计数。
- 整 BOL 退仓（1 柜 / 全选）**不生成** `-N` 子单。

### 4.3 其他不变项

- **装车单**：保持 **已发车**，不改为已取消、不回已装车。
- **计划单**：状态不变。
- **同装车单其他 BOL**：不受影响。
- **退仓类型**：记为 **单项退仓**。

### 4.4 示例

**整 BOL 退仓（1 柜）**

```
BOL-001（柜 A，运输中）
  → 通知退仓
BOL-001（柜 A，退仓待执行）   ← 无 BOL-001-1
```

**整 BOL 退仓（2 柜全选）**

```
BOL-002（柜 A、B，运输中）
  → 全选后通知退仓
BOL-002（柜 A、B，退仓待执行）   ← 仍为一个原 BOL
```

**部分退仓**

```
BOL-003（柜 A、B，运输中）
  → 勾选 B
BOL-003（柜 A，运输中）
BOL-003-1（柜 B，退仓待执行）
```

## 5. 确认退仓完成

### 5.1 操作对象

状态为 **退仓待执行**、退仓类型为 **单项退仓** 的 BOL，包括：

- 整 BOL 单项退仓（原 BOL 号）
- 拆分 BOL（`{原BOL}-N`）

入口：行「退仓完成」或弹窗「确认退仓完成」。

### 5.2 填写字段

| 字段 | 必填 |
|------|------|
| 实际到仓时间 | 是 |
| 退仓原因 | 是 |
| 详细说明 | 是 |
| 退仓凭证 | 否 |

### 5.3 系统处理

| 对象 | 列表 | 货件 | 原 BOL（部分退时） | 装车单 / 计划单 |
|------|------|------|-------------------|-----------------|
| **整 BOL 单项退仓** | 该行 **删除** | 回 **排货总览 · 在仓未排** | — | **不变** |
| **拆分 BOL `-N`** | 拆分行 **删除** | 回 **排货总览 · 在仓未排** | 不变，仍运输中 | **不变** |

> 单项退仓完成**不**进入「已退仓」终态 Tab，而是从 FBA 派送列表移除；货件解绑 BOL，计划单状态不变。

## 6. 撤销退仓

### 6.1 前置

- 仅 **退仓待执行** 可撤销。
- 入口：行「更多 → 撤销退仓」。

### 6.2 处理规则

| 对象 | 操作结果 |
|------|----------|
| **整 BOL 单项退仓**（原 BOL） | 状态 → **运输中**；清除退仓类型、期望到仓、退仓原因等字段 |
| **拆分 BOL**（`-N`） | **删除拆分行**；已退柜号**并回原 BOL**；**原 BOL 状态不变**（见 §6.3） |
| **整车退仓**（对比） | 同装车单下全部「整车退仓」BOL 一并恢复运输中；**不含**单项/拆分 BOL |

### 6.3 拆分撤销 · 原 BOL 已签收（边界）

**场景**：部分退仓后，原 BOL 剩余柜已送达并上传 POD → 原 BOL 变为 **已签收**；拆分 BOL `-N` 仍为 **退仓待执行**。

```
原 BOL-003（柜 A）→ 运输中 → 上传 POD → 已签收
拆分 BOL-003-1（柜 B）→ 退仓待执行
```

| 原 BOL 当前状态 | 撤销拆分 BOL `-N` | 说明 |
|-----------------|-------------------|------|
| **运输中** | **允许** | 删拆分行；柜号并回原 BOL；原 BOL 仍运输中 |
| **已签收** | **不允许** | 原 BOL 已完成签收，不可再把退仓柜并回在途 BOL |
| **退仓待执行** 等 | **不允许** | 原 BOL 非在途，状态不可回退 |

**阻断提示（建议）**：`原 BOL 已签收，无法撤销拆分退仓；请确认退仓完成。`

**业务含义**：拆分退仓一旦与原 BOL 签收并行存在，退仓侧只能 **确认完成**（货回排货总览），不能撤销并回原 BOL。

**可选预防（P1）**：原 BOL 存在 **退仓待执行** 的拆分 BOL 时，上传 POD 前二次确认：「存在拆分退仓待执行，签收后不可撤销拆分退仓。」

## 7. 与整车退仓对比

| | 单项退仓 | 整车退仓 |
|---|----------|----------|
| 维度 | BOL / 柜 | 装车单（同单全部 BOL） |
| 多柜全选 | **仍走单项**（原 BOL 整单退仓） | — |
| 通知后 | 整 BOL 或 `-N` → 退仓待执行 | 同单全部 BOL → 退仓待执行 |
| 退仓完成 | 货回排货总览；装车单不变 | 装车单 + 全部 BOL → **已装车** |
| 货件 | 回 **在仓未排** | **不回**在库 |

## 8. 流程图

```
运输中 BOL → 单项退仓弹窗
    │
    ├─ 1 柜 / 多柜全选 ──→ 原 BOL → 退仓待执行
    │                           │
    │                           ├─ 撤销 → 运输中
    │                           └─ 退仓完成 → 删行，货回排货总览
    │
    └─ 多柜部分选 ──→ 原 BOL 仍运输中 + 新建 {原BOL}-N（退仓待执行）
                              │
                              ├─ 撤销 -N → 删拆分行，柜并回原 BOL
                              └─ 退仓完成 -N → 删拆分行，货回排货总览
```

## 9. 验收要点

| # | 场景 | 预期 |
|---|------|------|
| 1 | 1 柜 · 通知退仓 | 原 BOL 退仓待执行；**无** `-1`；柜号勾选置灰 |
| 2 | 2 柜 · 全选 · 通知退仓 | 原 BOL 整单退仓待执行；**无** `-N` |
| 3 | 2 柜 · 选 1 柜 · 通知退仓 | 生成 `-1`；原 BOL 剩 1 柜仍运输中；预览显示具体 `-N` 号 |
| 4 | 整 BOL · 退仓完成 | 原 BOL 从列表删除；货回排货总览 |
| 5 | 拆分 BOL · 退仓完成 | 拆分行删除；原 BOL 不变 |
| 6 | 整 BOL · 撤销退仓 | 回运输中 |
| 7 | 拆分 BOL · 撤销退仓 | 原 BOL **运输中**：拆分行消失、柜并回；原 BOL **已签收**：**阻断** |
| 8 | 装车单 / 计划单 | 全程状态不变 |
| 9 | 同装车单其他 BOL | 不受影响 |
