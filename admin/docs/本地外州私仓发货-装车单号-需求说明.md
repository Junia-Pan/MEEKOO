# 本地 / 外州私仓发货 · 装车单号 — 需求说明

| 项目 | 说明 |
|------|------|
| 文档类型 | 产品需求（装车单号专项） |
| 涉及模块 | 本地私仓卡派（≤ 80 miles）、外州私仓卡派（> 80 miles） |
| 适用范围 | 员工端列表展示、BOL 详情、合并/拆分发货时的号段分配 |
| 关联原型 | `local-private-warehouse-shipping.html`、`out-of-state-private-warehouse-shipping.html` |
| 关联能力 | 与 **FBA 装车单管理** 共用同一套装车单号规则与全局号段 |

---

## 1. 背景与目标

### 1.1 背景

私仓卡派按 BOL 维度作业，现场与下游（装车、发车、PDA、对账等）需要稳定的「车次 / 装车」标识。FBA 侧已有装车单号（如 `LD2026050001`），私仓侧此前列表无对应字段，无法与 FBA 号段统一管理，合并发货时也缺少「同车同号」约定。

### 1.2 目标

| 类型 | 说明 |
|------|------|
| 定性 | 本地、外州私仓列表在 **POD 后** 增加 **装车单号**；编号规则与 FBA 一致，并与 FBA **共用全局号段**（FBA 已用过的号必须跳过） |
| 业务 | 普通 / 拆分：一 BOL 一号；合并发货：父单与全部子 BOL 共用同一号 |
| 范围 | 本地私仓、外州私仓 **同一套** 规则 |

### 1.3 本期不包含

- 不新建独立的「装车单管理」页面（私仓仍以 BOL 列表为主作业面）
- 不改变 FBA 装车单创建/状态流转本身的界面与流程（仅共用号段）
- 不强制本期增加装车单号筛选（可后续迭代；若加查询条件，须遵守「默认两行 / 展开更多」规范）

---

## 2. 名词解释

| 术语 | 定义 |
|------|------|
| 装车单号 | 系统自动生成的装车标识，格式见 §3；私仓挂在 BOL 上展示与使用 |
| 全局号段 | FBA 装车单与本地/外州私仓发货共用的装车单号序列；任一端占用后，另一端不得再发同号 |
| 合并发货 | 多个 BOL 合并为一个父单作业；父单下全部子 BOL 共用 **同一个** 装车单号 |
| 拆分发货 | 一个原货件拆成多个子 BOL；**原有 BOL 装车单号不变**，新拆出的 BOL 各发新号 |
| 普通发货 | 非合并、非拆分的独立 BOL；一 BOL 一装车单号 |

---

## 3. 装车单号生成规则（定稿话术）

**生成 BOL 的同时生成装车单号，一个 BOL 对应一个装车单号。** 操作拆分、取消拆分、合并、取消合并时按以下规则调整：

| # | 场景 | 规则 |
|---|------|------|
| （1） | 拆分 | **原有 BOL 的装车单号不变**；拆分出来的新 BOL 各自生成新的装车单号 |
| （2） | 取消拆分 | 恢复后的完整 BOL **生成新的装车单号**，不使用旧的装车单号 |
| （3） | 合并发货 | **发一个新的共享装车单号**，父单与全部子 BOL 均使用该同一号（不沿用任一原子 BOL 的旧号） |
| （4） | 取消合并发货 | 各恢复独立的 BOL **各自重新生成装车单号**，不使用合并时的共享号，也不恢复合并前旧号 |

**格式：** `LD` + `yyyyMM` + 4 位流水（与 FBA 一致）

**号段：** 与 FBA 全局共用，已占用号必须跳过

**分配：** 普通 / 拆分场景下一 BOL 一号；合并发货父子共用一号

---

## 4. 编号与分配细则

### 4.1 格式

```
LD + yyyyMM + 4位流水
示例：LD2026050001
```

| 段 | 含义 | 说明 |
|----|------|------|
| `LD` | 固定前缀 | Load 标识，与 FBA 一致 |
| `yyyyMM` | 年月 | 按号段归属月份（见 §4.2） |
| `4位流水` | 序号 | `0001` 起，同月内递增；不足四位左补 0 |

### 4.2 号段归属月份

| 约定 | 说明 |
|------|------|
| 默认 | 按 **生成当日** 的 `yyyyMM` 取号 |
| 跨月 | 进入新月份后，流水从该月 `0001` 起重新计；仍须跳过该月内已被占用的号 |

> 对接实现时，若业务要求按「预计发车月 / 装车月」取号，须与 FBA 装车单取号口径对齐后统一改；本期原型按生成当日月份演示。

### 4.3 与 FBA 共用、必须跳过

| 规则 | 说明 |
|------|------|
| 共用 | 私仓与 FBA **同一全局序列**，禁止各端独立从 `0001` 各算各的 |
| 跳过 | 取下一号时，若候选号已被 FBA（或本端其它 BOL/装车单）占用 → **跳过**，继续找下一可用号 |
| 旧号 | 取消合并 / 取消拆分后旧号本期 **不回收复用** |

**取号示意**

```
已占用（示例）：LD2026050001 … LD2026050008、LD2026050100、LD2026050101（FBA）
私仓下一可用：LD2026050009（跳过已占用，取同月最小未用流水）
```

### 4.4 生成时机与调整

| 场景 | 时机 | 行为 |
|------|------|------|
| 生成 BOL | 与 BOL 同时生成 | 系统自动分配 1 个装车单号（1 BOL = 1 号） |
| 拆分 | 拆分确认时 | **原有 BOL 号不变**；每个新拆出的 BOL **各发 1 个新号** |
| 取消拆分 | 恢复为一条完整 BOL 时 | 完整 BOL **发 1 个新号**（不使用任一旧号） |
| 合并发货 | 合并确认时 | **发 1 个新共享号**，写入父单并同步全部子 BOL |
| 取消合并 | 子 BOL 恢复独立时 | 各 BOL **各发 1 个新号**（不用共享号、不恢复合并前旧号） |

> **原有 BOL（拆分）：** 指拆分后仍留在列表中、承接原单身份的那一条（通常为 `-1` 或未改号主行）；其余新拆出的行视为「拆分出来的 BOL」。

### 4.5 示意

```
拆分前：BOL-X → LD…0020

拆分后：BOL-X-1 → LD…0020（原有，不变）
         BOL-X-2 → LD…0021（新拆出，新号）

取消拆分后：BOL-X → LD…0022（新号；不使用 0020 / 0021）
```

```
合并前：BOL-A → LD…0010
         BOL-B → LD…0011
         BOL-C → LD…0012

合并后：父单 BOL-M
         ├─ 子 BOL-A  ─┐
         ├─ 子 BOL-B  ├─ 共用 LD…0013（新共享号）
         └─ 子 BOL-C  ─┘

取消合并后：BOL-A → LD…0014（新号）
             BOL-B → LD…0015（新号）
             BOL-C → LD…0016（新号）
```

| 约束 | 说明 |
|------|------|
| 同组同号 | 同一合并组下父行与全部子行装车单号必须一致 |
| 只读 | 装车单号系统生成，列表与详情只读，不可人工改 |
| 子行 | 合并子 BOL 不可单独改装车单号；以父单为准 |

## 5. 界面需求

### 5.1 列表

| 项 | 要求 |
|----|------|
| 列位置 | 在 **POD** 列之后、**货件ID** 列之前，新增 **装车单号** |
| 本地 / 外州 | 两页均增加，列顺序与规则一致 |
| 合并父行 | 展示该组合并装车单号 |
| 合并子行 | 展示与父行 **相同** 的装车单号 |
| 空值 | 历史数据未回填前可显示 `—`；新单不得长期为空 |

### 5.2 BOL 详情

| 项 | 要求 |
|----|------|
| 展示 | 摘要区展示装车单号（与发货模式、货件数等信息一并可见） |
| 合并 | 打开父单或子单详情时，装车单号均为该组共享号 |

### 5.3 查询（可选 / 后续）

若增加「装车单号」查询条件：放入 **展开更多**（或与现有默认条件对调），不得默认撑出第三行查询区。

## 6. 关键业务规则表

| 场景 | 规则 |
|------|------|
| 编号格式 | `LD` + `yyyyMM` + 4 位流水 |
| 号段 | 与 FBA 装车单 **全局共用** |
| FBA 已用 | 私仓取号时 **必须跳过** |
| 生成 BOL | 同时生成装车单号；1 BOL ↔ 1 号 |
| 拆分 | 原有 BOL 号不变；新拆出 BOL 各发新号 |
| 取消拆分 | 完整 BOL 发新号，不使用旧号 |
| 合并发货 | 发新共享号；父子全部使用同一号 |
| 取消合并 | 各 BOL 各发新号，不使用旧号 |
| 旧号 | 取消后旧号本期不回收复用 |
| 编辑 | 系统生成，前端只读 |
| 本地 vs 外州 | 规则相同；号段全局唯一（跨本地/外州/FBA 不重复） |

## 7. 验收要点

| 编号 | 验收项 | 预期 |
|------|--------|------|
| A1 | 列表列位置 | POD 后可见「装车单号」；本地、外州均有 |
| A2 | 格式 | 符合 `LD` + `yyyyMM` + 4 位流水 |
| A3 | 跳过 FBA | 人为占用 FBA 号后，私仓下一号不落在已占用号上 |
| A4 | 普通 BOL | 各行装车单号互不相同 |
| A5 | 拆分 | 原有 BOL 装车单号不变；新拆出 BOL 为新号且互不相同 |
| A6 | 合并 | 父行与全部子行装车单号相同，且为合并时新发的共享号（不等于合并前任一旧号） |
| A7 | 合并后再取号 | 新合并组取得新号，且不与已有 FBA/私仓号重复 |
| A8 | 取消合并 | 各 BOL 均为新号、互不相同，且不等于取消前的共享号 / 合并前旧号 |
| A9 | 取消拆分 | 恢复后的完整 BOL 为新号，不等于取消前任一旧号 |
| A10 | 只读 | 无手工改号入口 |
| A11 | 详情 | BOL 详情可看到装车单号 |
| A12 | 跨端唯一 | 同月内 FBA 与私仓（本地+外州）不出现重复装车单号 |

## 8. 接口与数据（对接提示）

| 项 | 建议 |
|----|------|
| 发号服务 | 由服务端统一发号（建议独立号段服务或带悲观/乐观锁的序列表），禁止各端本地自增 |
| 占用查询 | 发号前校验全局已占用集合（含 FBA 装车单、私仓 BOL） |
| 字段落库 | BOL（及合并组）持久化 `loadNo`；合并组维度可冗余存一份便于同步 |
| 幂等 | 同一 BOL 创建请求重复提交不得连发多号 |
