# 提拆派报价 — PRD 截图目录

将界面截图（PNG/JPG）放在本目录，供 `提拆派报价需求文档.md` 引用。

## 建议文件名

| 文件 | 内容 |
|------|------|
| `01-列表页.png` | 报价列表全貌 |
| `02-编辑页-基础信息.png` | 编辑页顶部表单 |
| `03-编辑页-价目Tab.png` | 任一价目 Tab + 费用项绑定 |
| `04-状态与提示.png` | 只读态 / Toast / 报错（可选） |

## 截图建议

- 分辨率：宽度 1280～1920px，保证文字可读
- 敏感信息：客户名、金额等可打码
- 浏览器：与员工端验收环境一致（Chrome / Edge）
