# 拆柜时效表 — 产品需求文档 (PRD)

## 1. 文档说明

员工端「报表中心 · **拆柜时效表**」：按柜只读查看提柜→拆柜时效，支持查询与导出。界面以原型为准；本文写数据口径与业务规则。

### 1.2 名词解释

| 专有名词 | 解释/定义 |
|----------|-----------|
| 提柜日期 | 提拆派计划**实际提柜日期**（yyyy-mm-dd） |
| 拆柜日期 | 拆柜完成后的日期（yyyy-mm-dd） |
| 时效（天） | 拆柜日期 − 提柜日期（自然日；同日为 0） |
| 客户 | 客户简称（与提拆派计划一致） |
| 客户全称 | 客户主数据完整名称；无则空 |
| 柜型 | 计划箱型（如 20GP、40HQ） |
| 装柜混乱 / 柜子异常 | 拆柜报告标记，取「是」或「否」 |
| 拆柜备注 | 拆柜报告备注原文；无则空 |

## 2. 产品概述

### 2.1 背景与目标

按月核对各柜提柜到拆柜耗时，筛装柜混乱/异常柜，并导出复盘。数据来自提拆派计划与拆柜报告，本页只读。

| 角色 | 诉求 |
|------|------|
| 仓配 / 提拆派运营 | 按月看时效与异常标记 |
| 客服 / 单证 | 按客户、柜号、单号定位 |
| 管理 / 复盘 | 导出筛选结果 |

**本期不包含：** 汇总看板/趋势图；本页改数；按勾选导出；件数/重量/Move Type；客户端开放。

### 2.2 关联模块

| 模块 | 关系 |
|------|------|
| 提拆派计划 | 客户简称、柜号、提单号、系统单号、柜型、提柜日期、装柜地址 |
| 拆柜报告 | 拆柜日期、服务商、装柜混乱、柜子异常、拆柜备注；完成后进入本表 |
| 客户管理 | 客户全称与简称；查询下拉展示「全称(简称)」 |
| 供应商管理 | 拆柜服务商多选选项 |

---

## 3. 核心规则

1. **入表条件：** 已有拆柜日期；一行一柜；未拆柜/已取消不进表。  
2. **只读：** 不回写计划或拆柜报告。  
3. **路径：** 实际提柜 → 完成拆柜报告 → 进本表 → 查询/导出。  
4. **时效：** 拆柜日期 − 提柜日期（自然日）。两日期齐全则计算；缺一则时效为「—」；拆柜日早于提柜日视为异常数据，本表不拦截。

---

## 4. 功能说明

### 4.1 默认与重置

进入页面、点击重置：拆柜日期 = **当前月**首日至末日，其它条件清空，自动查询。重置不清空为「无日期」，始终回当月。

### 4.2 查询条件（默认两行，最多 8 项）

| 条件 | 规则 |
|------|------|
| 客户 | 多选；选项展示为 **全称(简称)**（与员工端其它列表一致）；选中后按**简称**精确匹配列表「客户」列；未选不限 |
| 柜号 / 提单号 / 系统单号 | 多值（空格/换行/逗号分隔）；包含匹配；空不限 |
| 拆柜日期 | 闭区间；起止可只填一侧；皆空不限 |
| 拆柜服务商 | 多选；精确匹配；未选不限 |
| 装柜混乱 / 柜子异常 | 全部 / 是 / 否 |
| 条件关系 | 且 |

柜型、客户全称、拆柜备注**仅列表/导出**，不进查询区。无命中提示暂无数据。

### 4.3 列表列（从左到右）

系统单号、客户、客户全称、柜号、提单号、柜型、拆柜服务商、提柜日期、拆柜日期、时效（天）、装柜地址、装柜混乱、柜子异常、拆柜备注。

- 空值展示「—」；装柜混乱/柜子异常未标记按「否」。  
- 支持分页、行勾选；全选仅当前页。  
- 本期导出**不依赖**勾选。

### 4.4 导出

导出**当前筛选全部行**（含未展示页），列顺序与列表一致（无勾选列）。无数据不可导出。文件名建议含「拆柜时效表」，中文可正常打开。

---

## 5. 界面要点

以原型为准。查询区两行 8 条件；客户多选展示「全称(简称)」、服务商多选；日期 yyyy-mm-dd；工具栏导出。

| 场景 | 反馈 |
|------|------|
| 无结果 | 暂无数据 |
| 导出无数据 | 提示不可导出 |
| 导出成功 | 提示成功 |
