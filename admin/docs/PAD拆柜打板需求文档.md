# PAD 拆柜打板 — 产品需求文档 (PRD)

## 1. 文档说明

仓内平板端承接提拆派「拆柜」任务：登录后从任务清单进入作业，按目的地满板、完工，并只读查看拆柜报告。界面以 PAD 原型为准；状态、门禁与校验以本文第 4 章及附录为准。

### 1.2 名词解释

| 专有名词 | 解释/定义 |
|----------|-----------|
| 柜 / 任务 | 一条拆柜作业（海运柜号或空运提单号、客户、运输方式等） |
| 未拆 / 拆柜中 | 清单标签与顶栏统计口径见 **4.3.2**（已到仓 + 拆柜报告未开始 / 进行中） |
| 目的地 | 本柜内按派送类型划分的打板单元（FBA 仓码、私卡派、自提、留仓、扣货等） |
| 合组组长 | 合并打板后列表展示的代表目的地；跟随目的地隐藏 |
| 未打板 / 打板中 / 已完工 | 目的地三态（判定见 **4.3.4**；允许/禁止见 **附录 A**） |
| 满板确认 | 登记一块板的「本板总件数」并追加板记录 |
| 合并打板 | 多条目的地/货件合组共用打板与完工；与 PC 打印板标主动合组同一模型 |
| 拆柜完毕 / 结束拆柜 | 侧栏必填齐全且全部目的地已完工后结束本柜；确认弹窗标题为「结束拆柜」 |
| 有效货件 | 未取消的货件 |
| 收费板数 | 与拆柜报告、打印板标同口径；未填回落实际板数 |

## 2. 产品概述

### 2.1 产品背景

拆柜现场需在平板认柜并按目的地打板留痕，合组与板数口径须与 PC 打印板标、拆柜报告一致。

### 2.2 目标用户

| 用户角色 | 特征与诉求 |
|----------|------------|
| 拆柜仓员 | 大触控、少跳转；尽快满板与完工 |
| 仓管 / 班组长 | 看清单进度；核对报告与异常 |
| 提拆派运营 | 与 PC 合组、板标、报告口径一致 |

### 2.3 产品目标

| 类型 | 目标说明 |
|------|----------|
| 定性 | 柜/目的地用语统一；合并打板与打印板标对齐；门禁可预期 |
| 定量 | 打开任务到首次满板路径短；无任务、跨类型合并、已完工误操作可拦截 |

### 2.4 关联模块

| 关联模块 | 与本模块关系 |
|----------|--------------|
| 提拆派计划 | 任务来源；业务类型为拆柜 |
| 打印板标 | 合组、板数、板标生命周期共用（**附录 B**） |
| 拆柜报告（员工端） | PAD 结果进入报告；PAD 只读查看 |
| 板标查询 / 上架出库 | 满板产生的板进入后续流程 |

## 3. 业务流程与架构

### 3.1 核心业务流程

1. 登录 → 任务清单。  
2. 点选柜任务 → 作业页（侧栏维护基础信息）。  
3. 「未拆」柜在首次进入目的地作业前确认「开始拆柜」→ 拆柜中并计时。  
4. 选目的地 → 按需合并打板 → 循环满板确认 → 确认已完工。  
5. 条件满足后拆柜完毕 → 回清单；按需打开报告。

允许/禁止见 **附录 A**；合并与整柜结束校验见 **4.3.6、4.3.9**。

### 3.2 页面流转

| 页面 | 进入 | 离开 |
|------|------|------|
| 登录 | 打开 PAD / 退出后 | 校验通过或自动登录 → 清单 |
| 任务清单 | 登录成功；拆柜完毕返回 | 点任务 → 作业；退出 → 登录 |
| 拆柜打板 | 清单选柜（须有效主单号） | 拆柜完毕 → 清单；打开报告 → 报告 |
| 拆柜报告 | 作业或约定入口 | 返回来源页 |

## 4. 需求详细说明

### 4.1 产品方案概述

相对易误解的产品取舍（状态名、流程步骤见第 3 章与名词解释，此处不复述）：

1. 进柜只走任务清单，作业页不再做选柜。  
2. 柜基础信息在侧栏维护并即时暂存；回任务清单再进同柜内容仍在；结束拆柜前才强制校验必填（无独立准备页）。  
3. 合并打板与 PC 打印板标共用一套合组规则，不另做平行合组。

### 4.2 核心功能索引

按现场路径排列（登录 / 清单 → 作业页主路径 → 按需动作 → 收工 → 报告）：

| 核心功能点 | 说明摘要 | 详述 |
|------------|----------|------|
| 登录与退出 | 空提交拦截；记住/自动登录互锁；退出清自动登录 | **4.3.1** |
| 任务清单 | 统计与海运/空运展示；点任务进作业 | **4.3.2** |
| 进入与开始拆柜 | 进页门禁；首次作业前计时确认 | **4.3.3** |
| 目的地列表与进入 | 三态、筛选搜索、合组展示 | **4.3.4** |
| 目的地作业 | 满板、改删板、确认已完工 / 撤回未完工 | **4.3.5** |
| 合并打板 | 选目的地后、满板前的按需合组 | **4.3.6** |
| 货件处理 | 扣货、取消恢复、异常、补录 | **4.3.7** |
| 收费板数 | 口径与修改 | **4.3.8** |
| 侧栏与拆柜完毕 | 即时暂存、按柜带回、结束校验、返回 | **4.3.9** |
| 拆柜报告 | 只读列表与详情 | **4.3.10** |

### 4.3 具体功能详述

#### 4.3.1 【登录】登录与退出

- **前置条件：** 账号已开通 PAD 权限。  
- **操作流程：**

**路径一：自动登录（打开应用时）**

1. 检测已存「自动登录」标记且账号非空 → **不进入登录页**，直接进任务清单。  
2. 不满足 → 走路径二。  

**路径二：手动登录**

1. 打开登录页；有已存账号/密码则回填；有自动登录标记且仍勾选记住则勾选「自动登录」。  
2. 用户提交账号、密码。  
3. 校验通过 → 按当前勾选写入「记住账号 / 自动登录」→ 进入任务清单。  
4. 校验失败 → 见业务规则（空账号/空密码/密码错误）。  

**退出**

1. 回登录页，并清除自动登录标记（记住账号默认可保留）。  

- **业务规则（核心）：**

| 规则 | 说明 |
|------|------|
| 空账号 | 去空格后为空 → 拦截，提示「请输入账号」 |
| 空密码 | 去空格后为空 → 拦截，提示「请输入密码」 |
| 记住 ↔ 自动登录 | 取消记住 → 强制取消自动登录，并清除已存账号、密码与自动登录标记；勾选自动登录 → 必须同时勾选记住 |
| 自动登录写入 | 仅当记住与自动登录均勾选且账号非空时写入标记 |
| 退出 | 必清自动登录；记住账号默认可保留；不得退出后再开登录页又立刻自动进清单 |
| 语言 | 支持切换中英文 |
| 密码错误 | 停留登录页，提示「账号或密码错误」 |

#### 4.3.2 【清单】任务清单与进入作业

- **操作流程：** 看统计 → 浏览任务卡 → 点卡进入作业（带主单号）。  
- **业务规则（核心）：**

**① 顶栏统计**

| 今日到仓 | 未拆 | 拆柜中 | 今日已拆 |
|----------|------|--------|----------|
| 到仓日期为当天 | 柜状态「已到仓」+ 拆柜报告状态「未开始」 | 柜状态「已到仓」+ 拆柜报告状态「进行中」 | 当日已完成拆柜的柜数 |

**② 任务卡展示**

| | 海运 | 空运 |
|--|------|------|
| 主单号 | 柜号 | 提单号 |
| 副文案 | 客户 · 柜型 | 客户 · 空运 |
| 状态标签 | **未拆** / **拆柜中** | 同左 |
| 每张都显示 | 预报件数/板数、地址数量汇总 | 同左 |

**③ 进入作业**

| 条件 | 处理 |
|------|------|
| 有有效主单号 | 进入该柜作业页 |
| 无主单号，或任务已取消 / 不存在 | 不进入；提示并刷新清单 |

#### 4.3.3 【作业】进入与开始拆柜

从任务清单点入本柜作业页后：

**① 进入作业页**

| 条件 | 处理 |
|------|------|
| 无有效主单号 | 立即回任务清单，不允许停留空白作业页 |
| 有有效主单号 | 进入作业页；可先看目的地列表与侧栏 |

**② 开始拆柜（计时）**

| 规则 | 说明 |
|------|------|
| 触发时机 | 首次真正进入某目的地作业（含进入合并勾选）前，若尚未计时 |
| 确认 | 弹「开始拆柜」；文案：「确认后将正式开始计时」→ 柜变拆柜中并计时 |
| 取消 | 不进入该目的地作业、不计时，柜保持未拆 |
| 之后 | 已是拆柜中时，再切目的地不重复确认 |

#### 4.3.4 【作业】目的地列表与进入

**① 目的地状态**

| 状态 | 判定 |
|------|------|
| 未打板 | 实际板数 = 0，且未标记已完工 |
| 打板中 | 实际板数 > 0，且未标记已完工 |
| 已完工 | 已执行「确认已完工」 |

```
未打板 --满板产生板--> 打板中 --确认已完工--> 已完工
已完工 --撤回未完工--> 打板中（有板）/ 未打板（无板）
```

**② 列表与进入**

| 规则 | 说明 |
|------|------|
| 列表顺序 | 状态优先：打板中 → 未打板 → 已完工；同状态时类型顺序与网页端一致（如 FBA → 私卡派等） |
| 合组展示 | 列表只显示组长；跟随目的地隐藏；组长标题为「编码 (合)」；预报 / 实际件数与板数按合组汇总 |
| 合组角标 | 合组内货件展示类型多于 1 种时：显示合组业务类型（如「扣货」）+「多类型」；仅 1 种时保持该类型角标 |
| 扣货角标（未合组） | 扣货目的地同时展示原类型角标 +「扣货」（预报本为扣货的可仅「扣货」） |
| 筛选 / 搜索 | 可按类型、状态、关键词；筛「扣货」时含预报扣货与现场改扣货 |
| 点卡片 | 进入该目的地（合组点组长进入合组作业） |
| 编码回车 | 精确 1 条或可见仅 1 条 → 进入；0 条 →「未找到匹配的目的地」；多条模糊 → 提示输入完整编码或点卡片 |
| 已完工 | 可进入查看；界面门禁见 **4.3.5③**（补录仍可用） |

#### 4.3.5 【作业】目的地作业（满板与完工）

选中目的地后的主路径。合并勾选进行中：禁止满板、完工、改收费板数、补录。目的地已完工时的按钮门禁见 **③**。

**① 满板与板维护**

| 规则 | 说明 |
|------|------|
| 满板 | 录入本板总件数；须 > 0，否则「请录入本板总件数」，不落板；已完工时入口隐藏 |
| 成功 | 追加 1 板；未打板变为打板中 |
| 改件数 | 须 > 0，否则「请输入件数」 |
| 删板 | 二次确认：「确认删除第 n 板（x 件）？」 |

**② 确认已完工**

| 规则 | 说明 |
|------|------|
| 操作 | 点「确认已完工」→ 二次确认 → 将当前目的地标为已完工；若在合组则整组一并完工（**保留合组关系**）→ 回目的地列表 |
| 确认文案 | 「确认该目的地已全部打板完毕？」 |

**③ 已完工时界面与撤回**

| 项 | 规则 |
|----|------|
| 满板确认 | **隐藏** |
| 确认已完工 | 按钮文案改为 **「撤回未完工」** |
| 更多 | **隐藏**（扣货、取消货件等写操作一并不可用） |
| 合并打板 / 取消合并 | 禁止（入口隐藏或不提供勾选） |
| 补录 | **允许** |
| 撤回未完工 | 二次确认后取消已完工标记：有实际板 → 打板中；无板 → 未打板；整柜已「拆柜完毕」后不再提供撤回 |
| 撤回文案要点 | 确认撤回未完工？撤回后可继续满板与货件处理 |

#### 4.3.6 【作业】合并打板（按需）

在选目的地之后、满板之前按需使用；与 PC 打印板标主动合组同一套规则（**附录 B**）。

**操作流程：** 打开「合并打板」→ 勾选 → 按序校验 → 二次确认完成合并（列表只显组长）→ 按需取消合并。

**校验顺序**

| 顺序 | 规则 | 失败提示要点 |
|:----:|------|--------------|
| 1 | 仅私卡派、留仓、自提、扣货可合并；FBA、Walmart 等不可勾选 | 说明仅上述类型可合并 |
| 2 | 至少 2 个相同类型目的地；按货件计时有效货件亦 ≥ 2 | 请至少勾选 2 个相同类型的目的地/货件 |
| 3 | 所选须为同一类型；勾选冲突即时拦截（留仓只能合留仓，扣货只能合扣货，以此类推） | 「X」只能与「X」合并打板 |
| 4 | FBA / 亚马逊按仓打板，不跨仓合并；PAD 不做 FBA 自动合组列表 | — |
| 5 | 目的地已完工 → 禁止 | — |
| 6 | 拆柜报告非「未开始」→ 禁止合并与取消合并（与 PC 对齐） | 仅报告未开始时可合并/取消 |

**已有板标（合并 / 取消合并）**

| 场景 | 规则 | 确认文案 |
|------|------|----------|
| 合并且所选范围内任一目的地已有板标 | 二次确认；确认后清空这些目的地的板标，实际件数/板数清零，状态变为「未打板」，再完成合并 | 标题「确认合并打板」；正文「所选目的地已有板标，确认合并？确认后将清空原有板标数据。」 |
| 合并且无板标 | 二次确认后完成合并 | 标题「确认合并打板」；正文「确认将所选 n 条「类型」货件合并打板？」 |
| 取消合并且合组内已有板标 | 二次确认；确认后清空合组内板标（状态变为「未打板」），再取消合并，各目的地分开显示 | 标题「确认取消合并」；正文「所选目的地已有板标，确认取消合并？确认后将清空原有板标数据。」 |
| 取消合并且无板标 | 二次确认后取消合并，按原目的地分开显示 | 标题「确认取消合并」；正文「确认取消合并？取消后按原目的地分开显示。」 |

合并勾选进行中：禁止满板、完工、改收费板数、补录。

扣货目的地如何参与合并：见 **4.3.7①**（合并校验与已有板标规则同 **4.3.6**）。

#### 4.3.7 【作业】货件处理（按需）

目的地已完工时隐藏「更多」，本节①②③入口不可用；补录见 **④**（已完工仍可用）。

**① 扣货**

在货件「更多」中操作：预报已是扣货 → **隐藏**「扣货」；现场已扣货 → 显示「取消扣货」。

| 操作 | 确认文案 | 结果 |
|------|----------|------|
| 扣货 | 确认扣货？扣货后将从当前分组拆出，单独作为扣货 | 货件进入扣货目的地（编码优先客户单号，冲突加「-扣货」）；原目的地预报按比例扣减，无货则暂不展示；原目的地若在合组则先退出（不足 2 个则取消合组）；列表角标为原类型 +「扣货」（见 **4.3.4**） |
| 取消扣货 | 确认取消扣货？取消后回到原分组 | 货件与板标回原目的地，预报加回；空的扣货目的地从列表删除；该扣货目的地若在合组则先退出（不足 2 个则取消合组） |

**与合并：** 扣货后按「扣货」类型合组——只能与其他扣货合（预报扣货、现场改扣货彼此可合），不能与 FBA / 私卡派等合；冲突提示「「扣货」只能与「扣货」合并打板」。入口、校验、有板标时的确认清板，均同 **4.3.6**；合组列表展示同 **4.3.4**。

**② 取消 / 恢复货件**

| 操作 | 确认文案要点 | 后果 |
|------|--------------|------|
| 取消 | 取消后需手动恢复 | 标已取消；列表置后；不计有效货件；若该目的地已无有效货件，询问是否标已完工（合组内均无货/已完工则整组完工，保留合组） |
| 恢复 | 确认恢复该货件 | 清除取消标记，重新计入有效货件 |

**③ 异常反馈**

| 规则 | 说明 |
|------|------|
| 登记 | 选货件 → 填异常说明、是否问题件 → 按需上传（点击或拖拽）→ 提交；必填：货件、异常说明、是否问题件 |
| 删除 | 须二次确认 |
| 定位 | 空输入 →「请输入或扫描 REF / FBA」；无匹配 →「未找到匹配货件」 |

**④ 补录**

| 规则 | 说明 |
|------|------|
| 必填 | Move Type、实际件数、实际板数；须已选目的地；未选 Move Type →「请选择 Move Type」 |
| Customer Ref No | 重复 →「客户单号已存在」；空则生成「补录-n」 |
| 收费板数 | 按需填写 |
| 锁定 | 合并勾选中不可补录；已完工仍可补录 |

#### 4.3.8 【作业】收费板数

| 项 | 规则 |
|----|------|
| 参考量 | 重量板数 = ⌈重量磅 / 1000⌉；体积板数 = ⌈方数 / 1.8⌉ |
| 收费板数 | 默认同实际板数，可改；须 ≥ 0 整数，非法 →「请输入收费板数」；合组展示为组内求和 |
| 锁定 | 合并勾选中不可改 |

#### 4.3.9 【作业】侧栏与拆柜完毕

**① 侧栏基础信息（无独立准备页）**

在作业页侧栏维护本柜基础信息，不另开准备页。

**暂存与带回**

| 规则 | 说明 |
|------|------|
| 何时保存 | 输入框、选项、开关、附件等变更后**即时暂存**（无需点「保存」） |
| 按柜记忆 | 按当前柜号 / 主单号分别保存 |
| 离开再进 | 返回任务清单后，再进入**同一柜**，侧栏内容仍在，可继续改 |
| 换柜 | 进入其他柜时加载该柜已暂存内容；互不影响 |

**字段**

| 项 | 结束前必填 | 规则 |
|----|:----------:|------|
| 柜号 / 主单号 | 是（带入） | 由任务清单带入，不可靠侧栏改柜 |
| 拆柜服务商 | 是 | 未选 →「请选择拆柜服务商」，并打开侧栏 |
| 拆柜人数 | 是 | ≥ 1；未填 →「请填写拆柜人数」 |
| 清点人员 | 是 | 可搜索 / 新建；新建姓名 ≤ 20 字 |
| 装柜混乱 / 柜子异常 / 备注 | 否 | 变更后即时暂存 |
| 附件 | 否 | 图片；单文件 ≤ 20MB；变更后即时暂存 |

必填项仅在「结束拆柜」时强校验（见 **②**）；平时可先填一部分、离开后再补。

**② 结束拆柜（拆柜完毕）**

| 顺序 | 规则 | 失败 / 提示 |
|:----:|------|-------------|
| 1 | 侧栏必填齐全 | 「请选择拆柜服务商」/「请填写拆柜人数」等，并打开侧栏，不结束 |
| 2 | 全部目的地须已完工 | 未全部完工 →「请先完成全部目的地」，不结束 |
| 3 | 二次确认 | 弹窗标题「结束拆柜」；正文「是否结束拆柜并停止计时？」；取消则留在作业页 |
| 4 | 实收件数 ≠ 预报件数 | 确认文案附加「实收 x 件，预报 y 件」；仍允许确认结束 |
| 5 | 用户确认 | 停表、回写、**回任务清单**（计入今日已拆） |

**③ 返回**

| 动作 | 规则 |
|------|------|
| 顶栏回清单 | 尚未拆柜完毕 → 二次确认后再离开；已完毕可直接回 |
| 回到目的地列表 | 不额外确认 |

#### 4.3.10 【报告】拆柜报告查看

独立只读页，**不在此页改**件数、板数、目的地状态。入口：任务清单或作业约定入口；返回来源页。

页面分两层：**报告列表** → 点某柜进 **报告详情**（含拆柜清单；板标在弹层查看）。

**① 报告列表**

| 规则 | 说明 |
|------|------|
| 排序 | 按拆柜日期倒序 |
| 筛选 | 全部 / 今天 / 昨天 / 自定义起止；柜号模糊；服务商 |
| 卡片字段 | 柜号、拆柜日期、时长、服务商、实际件数与板数、地址数量 |

**② 报告详情 · 柜头信息**

详情页顶部本柜摘要（对应作业侧栏落库结果），字段包括：客户、柜型、起止时间、服务商、人数、清点人员、装柜混乱、柜子异常、备注、附件。

另展示本柜汇总：

| 项 | 规则 |
|----|------|
| 件数 | 预报 vs 实际；不一致高亮 |
| 板数 | 预报 vs 实际 |
| 收费板数 | 单独展示 |

**③ 报告详情 · 拆柜清单**

按**目的地**分组列出货件。扣货目的地正常出现在清单中（类型可为扣货；货件可保留原类型语义，见 **4.3.6 / 4.3.7**）。已取消货件排在同组有效货件之后，并标「已取消」。

**目的地分组头（每组始终显示）**

| 字段 | 说明 |
|------|------|
| 类型角标、目的地编码 | — |
| 查看板标 | 打开该目的地板标弹层 |
| 件数 | 预报 / 实际；不一致高亮 |
| 板数 | 预报 / 实际 |
| 收费板数 | — |

**货件卡（组内每一票）**

| 展示方式 | 字段 | 空值 |
|----------|------|------|
| 始终显示 | 货件序号（货件 n）、单号（Customer Ref） | 单号空 →「—」 |
| 始终显示 | 类型角标 | 无类型则不画角标 |
| 始终显示 | FBA ID、PO | 空 →「—」 |
| 始终显示 | 重量、方数 | 按数值格式展示 |
| 始终显示 | 是否问题件 | 「是」/「否」 |
| 有条件显示 | 已取消角标 | 仅已取消货件显示 |
| 有值才显示整行 | 详细地址、拆柜要求、拆柜异常反馈、拆柜照片 | 无内容则不出现该行 |

**④ 板标弹层（从「查看板标」进入）**

| 规则 | 说明 |
|------|------|

### A. 状态与操作矩阵

| 对象 | 状态 / 情境 | 允许 | 禁止 |
|------|-------------|------|------|
| 柜 | 未拆 | 开始拆柜确认 | 拆柜完毕 |
