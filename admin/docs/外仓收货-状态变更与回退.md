# 外仓收货计划 · 状态变更与状态回退 — 产品需求文档 (PRD)

## 1. 文档说明

员工端外仓收货计划的**状态变更**、**状态回退**、**修改计划**、**取消计划**业务规则。

创建计划时三选一**提货方式**（§1.2），决定可走的状态路径及变更/回退业务规则（§3.2～§3.4）。

### 1.2 名词解释

| 术语 | 定义 |
|------|------|
| 计划状态 | 外仓收货计划单上的节点状态（如待提货、提货中、已到仓、直送运输中、直送已到达、已取消） |
| 货件状态 | **货件管理**模块中每条货件的状态（如已预报、在库、运输中、已送达、已取消） |
| 提货方式-提货回仓 | 安排司机上门把货**提回仓库** |
| 提货方式-自送 | 客户自行把货**送到仓库** |
| 提货方式-提货直送 | 安排司机上门提货后**直接送到目的地**，**不回仓** |
| 客户 BOL | 客户提供的提货授权书或原始提货单/发货单；**下单时**由客户上传；员工端仅查看、下载 |
| 收货 BOL | 到仓确认单；**计划级**附件；提货回仓/自送在计划**已到仓**后上传 |
| POD | 签收凭证；**货件级**附件；计划**直送已到达**时按货件上传 |

## 3. 按提货方式的规则

计划状态变更/回退时，按 **§3.1** 将本计划下**全部货件**的货件状态一并更新；回退时计划头与货件级字段按 §3.1 及下表「须满足」清理。**已取消**为计划与货件终态（不可变更、不可回退、不可修改）。

「变更」：状态变更菜单选定目标态 → 状态变更弹窗 → 确认。演示原型可字段平铺；正式按本次 **「从 → 到」** 仅展示对应字段与附件，并按 §3.2～§3.4「须满足」校验必填。  
「回退」：状态回退菜单选定目标态 → 回退弹窗（**回退原因必填**）→ 确认。  
**回退策略：** 支持跨级回退（可直接回退到该提货方式下任一更早节点）。

### 3.1 计划状态与货件状态

外仓收货计划视为**大包裹**（计划级状态）；计划下每条货件为**小包裹**（货件管理中的货件状态）。详情「货件动态」列表展示**货件状态**，不展示计划状态。

| 时机 / 计划状态（变更或回退后） | 货件状态（货件管理） | 说明 |
|--------------------------------|----------------------|------|
| **创建计划**（计划为待提货） | **已预报** | 创建计划即生成货件及货件 ID |
| 计划 **待提货** 或 **提货中** | **已预报** | 货未进库前，货件保持已预报 |
| 计划 **已到仓**（提货回仓 / 自送） | **在库** | 自送可由待提货一步到已到仓，货件由已预报一步到在库 |
| 计划 **直送运输中** | **运输中** | |
| 计划 **直送已到达** | **已送达** | 计划侧称「直送已到达」，货件侧为「已送达」 |
| **取消计划**（计划 → 已取消） | **已取消** | 下属货件全部变为已取消；货件管理中**不可再操作** |
| **修改计划**（计划仍为待提货） | **不变** | 仅改预报信息，货件状态仍为已预报 |

**直送 · 计划时间与货件字段（变更时写入，回退时按 §3.4 清除）：**

| 计划变更为 | 货件字段 |
|------------|----------|
| 直送运输中 | **出发日期** ← 计划填写的**实际提货时间** |
| 直送已到达 | **签收日期** ← 计划填写的**直送送达时间**；各货件 **POD** |

**回退 · 附件与清理范围：**

| 附件 / 数据 | 粒度 | 回退时 |
|-------------|------|--------|
| 收货 BOL | 计划级 | 回退离开「已到仓」时清除计划上的收货 BOL |
| POD | 货件级 | 回退离开「直送已到达」时删除各货件 POD；日志记录各货件已删文件名 |
| 司机、板数、时间等 | 计划 + 货件 | 与 §3.2～§3.4「须满足」中清除项一致，**货件级字段同步清空** |

### 3.2 提货回仓

**计划状态：** 待提货 → 提货中 → 已到仓（货件状态联动见 §3.1）

| 类型 | 从 | 到 | 须满足 |
|------|----|----|--------|
| 变更 | 待提货 | 提货中 | 填写：**提货供应商**、**司机姓名**、**司机电话号码**、**车牌号** |
| 变更 | 提货中 | 已到仓 | 填写：**实收板数**、**实际提货时间**、**到仓时间**；上传/关联**收货 BOL**（计划级） |
| 回退 | 提货中 | 待提货 | 填写**回退原因**；清除**提货中**相关信息：提货供应商、司机姓名、司机电话号码、车牌号等 |
| 回退 | 已到仓 | 待提货 / 提货中 | 填写**回退原因**；清除**已到仓**及**提货中**相关信息：实收板数、实际提货时间、到仓时间、收货 BOL、提货供应商、司机、车牌号等 |

**禁止：** 待提货直跳已到仓；进入直送相关状态。

---

### 3.3 自送

**计划状态：** 待提货 → 已到仓（无提货中、无直送；货件：已预报 → 在库）

| 类型 | 从 | 到 | 须满足 |
|------|----|----|--------|
| 变更 | 待提货 | 已到仓 | 填写：**实收板数**、**实际提货时间**、**到仓时间**；上传/关联**收货 BOL**（计划级） |
| 回退 | 已到仓 | 待提货 | 填写**回退原因**；清除**已到仓**相关信息：实收板数、实际提货时间、到仓时间、收货 BOL 等 |

**禁止：** 进入提货中或直送相关状态。

---

### 3.4 提货直送

**计划状态：** 待提货 → 提货中 → 直送运输中 → 直送已到达（无已到仓、无收货 BOL；货件联动见 §3.1）

| 类型 | 从 | 到 | 须满足 |
|------|----|----|--------|
| 变更 | 待提货 | 提货中 | 填写：**提货供应商**、**司机姓名**、**司机电话号码**、**车牌号** |
| 变更 | 提货中 | 直送运输中 | 填写：**实收板数**、**实际提货时间**、**到仓时间** |
| 变更 | 直送运输中 | 直送已到达 | 填写：**直送送达时间**；按货件上传 **POD** |
| 回退 | 提货中 | 待提货 | 填写**回退原因**；清除**提货中**相关信息：提货供应商、司机姓名、司机电话号码、车牌号等 |
| 回退 | 直送运输中 | 待提货 / 提货中 | 填写**回退原因**；清除**直送运输中**及**提货中**相关信息（含实收板数、实际提货时间、到仓时间、货件出发日期等） |
| 回退 | 直送已到达 | 直送运输中 / 提货中 / 待提货 | 填写**回退原因**；清除**直送已到达**、**直送运输中**及**提货中**相关信息（直送送达时间、货件签收日期、各货件 POD，以及运输中/提货中字段）；日志记录已删 POD 文件名；**建议二次确认** |

**禁止：** 提货中直跳直送已到达（必须先经直送运输中）；进入「已到仓」状态；使用收货 BOL。

---

### 3.5 修改计划 / 取消计划

**修改计划**按当前计划状态区分可编辑范围（**员工端、客户端**规则一致）：

| 计划状态 | 可编辑范围 |
|----------|------------|
| **待提货** | 可修改**全部**预报信息（基础信息 + 货件信息，与创建计划字段一致） |
| **提货中**、**已到仓** | **不可修改**计划基础信息（只读展示）；货件信息**仅可维护** **预约要求**、**预约文件**，其余货件字段只读 |
| **直送运输中**、**直送已到达**、**已取消** | **不可修改**（不提供「修改计划」或入口置灰/提示不可改） |

| 操作 | 规则 |
|------|------|
| **修改计划** | 上表；**不改变计划状态**；货件状态**不变**（见 §3.1）；货件表头字段名使用 **预约要求**（非「预约备注」） |
| **取消计划** | **仅待提货**；二次确认；计划状态 → **已取消**；本计划下全部货件 → **已取消**（非状态回退，作废后不可再变更/回退/修改） |

## 4. 操作日志

记录：状态变更、状态回退（含完整回退原因）、修改计划、取消计划；含操作人、时间。回退删除附件时：计划级收货 BOL、**各货件**已删 POD 文件名分别记录。
