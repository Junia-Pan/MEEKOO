# 本地 / 外州私仓发货 · 新增「待处理」状态 — 需求说明

| 项目 | 说明 |
|------|------|
| 文档类型 | 产品需求（状态节点专项） |
| 涉及模块 | 本地私仓卡派（≤ 80 miles）、外州私仓卡派（> 80 miles） |
| 适用范围 | 员工端列表、筛选、状态 Tab、行操作、状态变更/回退、BOL 详情进度条与操作 |
| 关联原型 | 本地私仓卡派、外州私仓卡派（两页规则一致） |

---

## 1. 背景与目标

### 1.1 背景

原私仓卡派主路径以 **处理中** 为起点，操作员打开「安排出库」即需填写完整出库排期与车辆信息。业务上希望在正式排期前增加一个轻量节点，仅记录预约侧备注，再进入处理与出库安排。

### 1.2 目标

| 类型 | 说明 |
|------|------|
| 定性 | 新增初始状态 **待处理**；将「填备注」与「填出库排期」拆成两步，降低误排期、便于先沟通后排期 |
| 范围 | 本地私仓、外州私仓 **同一套** 状态与交互规则 |

### 1.3 本期不包含

- 暂缓处理、退仓待执行 **不纳入** 主进度条（仍为旁路异常状态，规则沿用现网）
- 不改变运输中及之后节点的业务规则（已发车、上传 POD、签收等）

---

## 2. 名词解释

| 术语 | 定义 |
|------|------|
| 待处理 | BOL 新建后的初始状态；尚未进入出库排期填写 |
| 处理中 | 已确认进入处理；可填写完整出库安排并变为待取货；可合并/拆分、暂缓等（规则同原处理中） |
| 预约备注 | 待处理进入处理中时可填写的备注；选填；后续「安排出库」时回显并可修改覆盖 |
| 安排出库 | 处理中 → 待取货 的操作；须填写备货仓、预计发车/送达、发车类型等出库信息 |
| 主进度条 | BOL 详情展示的主路径节点：待处理 → 处理中 → 待取货 → 运输中 → 已签收 |

---

## 3. 状态模型

### 3.1 主路径

```
待处理 → 处理中 → 待取货 → 运输中 → 已签收
```

| 状态 | 说明 |
|------|------|
| 待处理 | **新建 BOL 初始状态** |
| 处理中 | 已填写（或跳过）预约备注后进入；可安排出库 |
| 待取货 | 已完成出库安排 |
| 运输中 | 已发车 |
| 已签收 | 已签收办结 |

### 3.2 旁路状态（不进入主进度条）

| 状态 | 说明 |
|------|------|
| 暂缓处理 | 暂停流转；解除后恢复为 **待处理** |
| 退仓待执行 | 退仓流程中（规则沿用现网） |

### 3.3 列表与详情展示

| 位置 | 要求 |
|------|------|
| 状态筛选 | 增加「待处理」选项 |
| 状态 Tab | 在「全部」之后增加「待处理」Tab，并统计数量 |
| BOL 详情主进度条 | 增加「待处理」为首节点；**不含**暂缓处理、退仓待执行 |

---

## 4. 状态流转与操作

### 4.1 待处理 → 处理中

| 项 | 说明 |
|----|------|
| 行操作按钮文案 | **处理中** |
| BOL 详情底部按钮 | 同为 **处理中** |
| 弹窗 | 仅 **预约备注** 一个字段 |
| 预约备注 | **选填** |
| 确认后 | 状态变为 **处理中**；不要求填写备货仓、发车时间、车型、承运商等 |
| 确认按钮文案 | **确认处理中** |

**操作流程**

1. **打开：** 在待处理 BOL 上点击「处理中」（列表或详情）。
2. **填写：** 按需填写预约备注。
3. **确认：** 提交后状态为处理中；已填备注写入并保留，供后续安排出库回显。

### 4.2 处理中 → 待取货（安排出库）

| 项 | 说明 |
|----|------|
| 行操作 / 详情按钮文案 | **安排出库**（不变） |
| 表单 | 沿用现有安排出库整表单（备货仓、预计发车时间、发车类型、预计送达时间、车型、月台、派送供应商、实际承运卡司、卡司提货时间、车牌号、预约备注等） |
| 预约备注回显 | 打开弹窗时回显待处理→处理中阶段已保存的预约备注，允许修改 |
| 备注保存策略 | 提交时 **覆盖** 原预约备注 |
| 确认后 | 状态变为 **待取货**；出库排期信息按现网规则落库/展示 |

**必填项：** 与现网「安排出库」一致（备货仓、预计发车时间、发车类型、预计送达时间等）。

### 4.3 取消出库安排（待取货 → 处理中）

| 项 | 说明 |
|----|------|
| 目标状态 | 仍回退为 **处理中**（不回待处理） |
| 出库排期 | 按现网取消安排规则释放/清空 |
| 预约备注 | **保留**（再次安排出库时继续回显） |

### 4.4 状态回退：处理中 → 待处理

| 项 | 说明 |
|----|------|
| 入口 | 工具栏「状态回退」→ 回退至 **待处理** |
| 须满足 | 勾选目标 BOL；填写回退原因（必填） |
| 确认后 | 状态变为 **待处理**；**清空预约备注** |

### 4.5 其他回退目标

| 回退至 | 说明 |
|--------|------|
| 处理中 | 沿用现网（如从待取货等场景回退时的清理规则） |
| 待取货 | 沿用现网 |

## 5. 业务规则汇总

| 序号 | 规则 |
|:----:|------|
| R1 | 新建 BOL 初始状态为 **待处理** |
| R2 | 待处理 → 处理中：仅预约备注（选填），不采集出库排期字段 |
| R3 | 处理中 → 待取货：完整安排出库表单；预约备注回显可改，提交覆盖 |
| R4 | 待取货取消安排 → **处理中**；预约备注不清空 |
| R5 | 处理中回退至待处理：清空预约备注 |
| R6 | 本地私仓与外州私仓规则一致 |
| R7 | 主进度条不含暂缓处理、退仓待执行 |
| R8 | 合并发货、拆分发货、转仓等仍仅允许在 **处理中**（及现网已约定的其它条件）下操作；待处理不可合并/拆分/转仓 |
| R9 | 暂缓处理入口为待处理 / 处理中 / 待取货；解除暂缓后恢复为 **待处理** |

---

## 6. 界面要点

界面以现有原型为准。下列仅列业务约束：

### 6.1 列表

- 待处理行主按钮为 **处理中**；处理中行主按钮为 **安排出库**。
- 状态 Tab、状态下拉筛选含 **待处理**。
- 状态变更菜单可含变更为 **处理中**（与其它目标状态一并展示）。
- 状态回退菜单增加回退至 **待处理**。

### 6.2 弹窗

| 场景 | 约束 |
|------|------|
| 待处理 → 处理中 | 仅预约备注；选填；确认后只改状态 |
| 处理中 → 待取货 | 完整出库表单；备注回显；必填项校验同现网 |

### 6.3 BOL 详情

- 主进度条节点：待处理、处理中、待取货、运输中、已签收。
- 待处理时底部主操作文案为 **处理中**；处理中时为 **安排出库**。
- 待处理、处理中且尚无出库安排时，流转信息区可为空态提示。

## 7. 验收要点

| 编号 | 验收项 | 预期 |
|------|--------|------|
| A1 | 新建/示例待处理 BOL | 状态为待处理；列表与 Tab 可筛出 |
| A2 | 待处理点「处理中」，不填备注确认 | 进入处理中 |
| A3 | 待处理填写备注后确认，再点「安排出库」 | 备注已回显 |
| A4 | 安排出库时修改备注并确认 | 备注被覆盖；状态为待取货 |
| A5 | 待取货取消安排 | 回到处理中；备注仍在，再次安排可回显 |
| A6 | 处理中回退至待处理 | 状态为待处理；备注已清空 |
| A7 | BOL 详情进度条 | 含待处理为首节点；无暂缓/退仓节点 |
| A8 | 本地与外州两页 | 行为一致 |
