# 提拆派 · 提还柜登记 / 批量提还柜 / 供应商标记 操作说明

页面：员工端「提拆派计划」。列表勾选计划后，使用工具栏三个按钮：

| 按钮 | 什么时候用 |
|------|------------|
| 提还柜登记 | 只处理 **1 条**，可同时登记时间、DOCK、停放位置和照片 |
| 批量提还柜登记 | 一次处理多条时间（**不含**停放） |
| 供应商标记 | 给勾选计划打上或去掉「已确认数据 / 已下载 DO」 |

「已取消」的计划不能做提还柜登记和批量提还柜登记。

时间一律按 `yyyy-mm-dd HH:mm` 填写，例如 `2026-09-26 09:00`。

---

## 1. 提还柜登记（单条）

### 怎么打开

1. 在列表勾选 **1 条**计划。
2. 点「提还柜登记」。
3. 核对弹窗顶部的系统单号、柜号、状态、业务类型。
4. 改完点「提交」。

勾了多条会提示改用「批量提还柜登记」。打开时，计划上已有的预计、实际、还空、停放、备注都会带出来；当时不能改的字段也看得到，只是不能改。

### 能填什么

| 字段 | 说明 |
|------|------|
| 预计提柜时间 | 见下方状态表 |
| 实际提柜时间 | 只记时间，**不会**把状态改成已到仓 |
| DOCK / 停放位置 / 停放位置照片 | 都不是必填。照片支持点击或拖拽，JPG / PNG / WEBP / GIF，可多张 |
| 还空时间 | 只有到了还空节点才能填 |
| 备注 | 可改 |

### 按当前状态能做什么

| 当前状态 | 可以改 | 提交后 |
|----------|--------|--------|
| 未到港 | 预计、实际、DOCK、停放、照片、备注。还空不能填 | 填了预计 → **待提柜** |
| 待提柜 | 同上 | 改时间、停放，状态不变 |
| 已到仓 / 直送运输中 | 同上。可以清空预计或实际 | 见下方「清空怎么回退」 |
| 已拆柜 / 直送已到达 | **只能填还空**，其它只读 | 须已有实际提柜时间；填了还空 → **已还空** |
| 已还空 | **只能改还空**，不能清空 | 状态不变 |
| 已取消 | 打不开 | — |

### 填写规则

- 可以只填预计、不填实际。
- **不能只填实际、不填预计。**
- 实际提柜不能早于预计提柜；还空不能早于实际提柜。
- 把某个时间框清空再提交，表示清空这一项（已还空的还空时间除外）。
- 清空「预计提柜时间」：状态回到 **未到港**，并同时清掉实际提柜时间、DOCK、停放位置和照片。
- 「已到仓」或「直送运输中」只清空实际、预计还在：状态回到 **待提柜**。

到仓本身不在这个弹窗里改。状态改成「已到仓」仍走工具栏「状态变更」；到仓时间必填，实际提柜时间不是必填。

## 2. 批量提还柜登记

### 怎么打开

1. 勾选一条或多条。
2. 所选计划必须 **状态相同**，并且 **业务类型相同**（都是拆柜，或都是直送）。
3. 点「批量提还柜登记」。

状态或业务类型不一致时，点按钮会直接提示，弹窗不会打开。

### 表格里有什么

每一行带出：系统单号、柜号、提单号、预计提柜、实际提柜、还空、备注。

- 原来只有日期、没有时刻的，会按当天 `09:00` 显示，提交前可以改。
- 当时不能改的列（例如已拆柜时的预计、实际）同样带出来，但不能改。
- **没有** DOCK、停放位置、照片。要登记停放，请只勾一条，用「提还柜登记」。

### 多条填同一个时间

表头每一列时间下面有一个统一填写框和「应用到全部」：

1. 在表头填好时间（格式同样是 `yyyy-mm-dd HH:mm`）。
2. 点「应用到全部」，这一列各行都会变成这个时间。
3. 某一行需要不同时间，再单独改那一行。

当前状态不允许填的那一列，表头输入框是灰的。打开时如果所选各行某个时间完全一样，表头会预先带上这个时间；不一样就留空，避免一键盖掉原来的值。

### 提交时怎么算

规则与单条相同：时间先后、禁止只填实际、填还空后变「已还空」、清空预计会回退等，都按每一行单独判断。

- 某一行原来带出来的时间被删空再提交，表示清空这一项。
- 某一行没有改过的格子，保持原值。
- 某一行不符合规则时，整批不会提交，提示会指出是第几行。

## 3. 供应商标记

标记只表示供应商是否处理过，**不改变计划状态**。

两种标记，一次只处理一种：

- **已确认数据**
- **已下载 DO**

### 打标 / 清除

1. 勾选一条或多条（状态可以不一样）。
2. 点「供应商标记」。弹窗显示「已选 N 条数据」。
3. 选择标记类型。
4. 点「确认标记」打上，或点「清除标记」去掉。

同一条可以同时有两种标记。列表「供应商标记」列只展示结果，例如 `已确认数据, 已下载DO`；没有标记时显示 `—`。这一列不能点击修改，要改请再走「供应商标记」。

清除只清当前选中的那一种，另一种还在。

### 按标记查找

查询区展开更多后，「供应商标记」是左右两个下拉：

1. 左边选 **有** 或 **无**。
2. 右边选 **已确认数据** 或 **已下载 DO**。
3. 两个都选好，再点「查询」。

例如：左边「有」、右边「已确认数据」，只看已经确认过数据的计划。只选一边不会按标记过滤。

### 在详情里看

打开计划详情，切到「提还柜信息」：

- 供应商标记：有则用逗号隔开，没有则是 `—`
- 预计 / 实际 / 到仓 / 还空、DOCK、停放位置、照片：与登记结果一致，照片可点开大图

详情里不能改标记、也不能改停放。改标记用「供应商标记」，改时间和停放用「提还柜登记」。

## 4. 点了没反应时先看这几条

| 提示大意 | 处理 |
|----------|------|
| 请先勾选要操作的计划行 | 先勾选列表 |
| 提还柜登记仅支持单条 | 只留 1 条，或多条改走批量 |
| 请选择状态相同 / 业务类型相同的计划 | 批量时拆开勾选 |
| 「已取消」不可操作 | 已取消计划跳过 |
| 填写实际提柜前须先填写预计 | 先补预计，或把实际一并清空 |
| 实际不能早于预计 / 还空不能早于实际 | 改时间先后 |
| 请先登记实际提柜时间后再填还空 | 这条还没有实际提柜，先补实际（须在已拆柜 / 直送已到达之前的状态补） |
| 还空须在已拆柜 / 直送已到达后填写 | 还空不要在到仓前填 |
| 已还空仅可改正还空，不可清空 | 只能改成另一个时间 |
| 时间格式应为 yyyy-mm-dd HH:mm | 按示例重填，不要用中文日期 |
