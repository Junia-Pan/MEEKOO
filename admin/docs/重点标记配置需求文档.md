# 重点标记配置 — 产品需求文档 (PRD)

## 1. 文档说明

明确员工端重点标记的配置与在提拆派计划、外仓收货计划上的展示、打标规则。一张单可同时存在多个标记，按显示优先级决定谁先展示，**不限制单据流转**。

### 1.1 修订记录

| 版本号 | 修订日期 | 修订人 | 修订说明 |
|--------|----------|--------|----------|
| V1.0 | 2026-08-17 | — | 初稿 |

### 1.2 名词解释

| 专有名词 | 解释/定义 |
|----------|-----------|
| 手工标记 | 用户手动打上或取消的标记 |
| 系统标记 | 按规则自动打上；条件不满足时自动取消 |
| 显示优先级 | 一张单有多个标记时，决定谁先展示 |
| 应用模块 | 该标记可用的业务页：提拆派计划、外仓收货计划 |
| 二次识别 | 某张计划在指定操作发生时，按当前启用的系统规则重新判断：满足则打上，不满足则取消 |

## 2. 产品概述

### 2.1 产品背景

提拆派计划、外仓收货计划需要标出需关注的单据。原先标记写死在业务页，无法统一维护名称、类型、优先级和自动规则。需在基础数据集中配置，业务页按配置展示与打标。

### 2.2 目标用户

| 用户角色 | 特征与诉求 |
|----------|------------|
| 运营 / 管理员 | 维护标记、规则、启用状态，并能查日志 |
| 计划员 / 仓配 | 在提拆派、外仓收货计划上看标记、打手工标记 |

### 2.3 产品目标

| 类型 | 目标说明 |
|------|----------|
| 定性 | 手工与系统两类标记可配置；系统标记按全部条件自动打上或取消 |
| 定性 | 多标记按 紧急 > 优先 > 普通 展示，同级按名称；不限制流转 |
| 定性 | 编辑配置不处理历史单据；仅在计划被创建或发生指定操作时二次识别 |

**本期不包含：**

- 系统标记同时绑定多个模块
- 同一业务项在一条规则里出现两次
- 用标记拦截或限制单据状态流转
- 保存配置时全量扫描历史单据、一次性打上或摘掉标记

### 2.4 关联模块

| 关联模块 | 与本模块关系 |
|----------|--------------|
| 提拆派计划 | 列表/详情展示标记；手工打标；指定操作时二次识别系统标记 |
| 外仓收货计划 | 同上 |
| 角色权限 | 配置页与业务页打标按权限控制 |

## 3. 业务流程与架构

### 3.1 核心业务规则总览

1. 管理员在重点标记配置中维护标记（名称、显示优先级、样式、类型、应用模块、规则、状态）。
2. **手工标记：** 用户在对应计划页手动打上或取消。
3. **系统标记：** 仅在计划 **创建** 或发生 **状态变更、状态维护、时间维护、编辑计划** 时，按当前规则二次识别：全部条件满足则打上，否则取消。编辑配置本身不改历史单。
4. 一张单多个标记时，按 **紧急 > 优先 > 普通** 排序；优先级相同按 **标记名称** 排序。

### 3.2 系统打标判断

对每一条**启用中的系统标记**，只在其绑定的那一个模块内、且发生 3.1 所列操作时执行：

- 该模块下全部条件都成立 → 打上此标记（已有则保持）
- 任一条件不成立 → 取消此标记（没有则不处理）

示例：标记「未派拖车」绑定提拆派计划，条件为「拖车供应商为空」→ 未选拖车供应商时打标，选定后在下一次指定操作时取消。

## 4. 需求详细说明

### 4.1 产品方案概述

1. 配置页维护全量标记；业务页使用已启用、且应用模块包含本页的标记。
2. 显示优先级只管展示顺序；新增默认普通。
3. 手工标记可多选模块；系统标记只能选一个模块，并只配该模块规则。

### 4.2 核心功能一览

#### 4.2.1 核心能力

| 序号 | 核心能力 | 解决什么问题 | 关键功能点 |
|:----:|----------|--------------|------------|
| ① | **标记维护** | 名称、类型、优先级、规则可统一改 | 新增 / 编辑；列表含类型、显示优先级、自动规则 |
| ② | **显示优先级** | 多标记时分得清谁先展示 | 紧急 > 优先 > 普通；同级按名称 |
| ③ | **标记类型** | 区分人工与自动 | 手工可多模块；系统单模块 |
| ④ | **系统触发与二次识别** | 条件变化后自动打上或取消 | 不扫历史；仅创建及指定操作时识别 |
| ⑤ | **操作日志** | 配置变更可追溯 | 新增记全量；修改只记变化项 |

#### 4.2.2 核心功能点索引

| 核心功能点 | 说明摘要 | 详述章节 |
|------------|----------|----------|
| 配置列表 | 类型、显示优先级、自动规则；不含文字颜色、背景颜色列 | **4.3.1** |
| 显示优先级与样式 | 新增默认普通；紧急 > 优先 > 普通 | **4.3.2** |
| 手工标记 / 系统标记 | 多选 / 单选模块与规则卡 | **4.3.3** |
| 系统触发规则 | 可判断项、运算符、取值 | **4.3.4** |
| 编辑与二次识别 | 历史单不处理；类型切换确认 | **4.3.5** |
| 操作日志 | 新增记全量，修改只记变化项 | **4.3.7** |
| 提拆派 / 外仓收货 | 排序、触发时机、详情位置 | **4.3.6** |

### 4.3 具体功能详述

#### 4.3.1 【配置】列表

- **使用场景：** 查看、筛选、新增、编辑标记，查看日志。
- **前置条件：** 具备重点标记配置权限。
- **操作流程：**
  1. **进入：** 基础数据 → 重点标记配置。
  2. **筛选：** 按需切换全部 / 手工标记 / 系统标记。
  3. **维护：** 新增或编辑；点日志查看该标记的配置变更。

**列表列（相对原列表）**

| 列 | 要求 |
|----|------|
| 类型 | 新增。展示手工 / 系统 |
| 显示优先级 | 新增。紧急 / 优先 / 普通 |
| 自动规则 | 新增。系统标记展示条件摘要；手工为「—」 |
| 文字颜色、背景颜色 | **去掉**，不再作为列表列 |

其余列（标记名称、预览效果、应用模块、状态、创建/修改信息、操作）以原型为准。操作含编辑、日志。

**自动规则展示**

- 不写模块名（模块已在「应用模块」列，系统标记只能选一个）。
- 多条条件用 **且** 拼接成一句。例如：拖车供应商为空 且 自带车架等于否。
- 一条条件则只写该条件，例如：拖车供应商为空。

- **业务规则（核心）：**
  - 状态为 **启用** 的标记，才允许在对应业务页新打（手工）或参与二次识别（系统）。
  - 状态为 **停用**：不能新打；系统标记不再二次识别。已打在单据上的该标记保留，不批量清除。

#### 4.3.2 【配置】显示优先级与样式

- **使用场景：** 约定多标记时的展示顺序，并设定标签配色（用于预览与业务页展示，不在配置列表单列颜色）。
- **业务规则（核心）：**

| 显示优先级 | 含义 | 默认配色 |
|------------|------|----------|
| 紧急 | 最先展示 | 红字、浅红底 |
| 优先 | 其次 | 橙字、浅橙底 |
| 普通 | 最后 | 蓝字、浅蓝底 |

  - 可选值顺序为 **紧急 > 优先 > 普通**。
  - **新增时默认「普通」**，并带出普通的默认配色；编辑时回显已保存的优先级。
  - 切换显示优先级时带出上表默认配色，仍可再改文字颜色、背景颜色。
  - 可用推荐色系快速选择：红色预警、橙色警告、绿色安全、蓝色常规、紫色特殊、灰色中性。
  - 名称与颜色变化时，弹窗内实时预览。

#### 4.3.3 【配置】标记类型与应用模块

| 类型 | 打标方式 | 应用模块 | 规则 |
|------|----------|----------|------|
| 手工标记 | 用户手动打上或取消 | 可同时勾选提拆派计划、外仓收货计划（至少选一个） | 无自动规则 |
| 系统标记 | 条件全部满足则打上，否则取消 | **只能选一个**模块 | 选中后展开该模块规则卡，须至少一条有效条件 |

- 业务页不能手工打上或取消系统标记。
- 应用模块只在表单选一次；规则区不再重复选模块。

#### 4.3.4 【配置】系统触发规则

- **前置条件：** 标记类型为系统标记，且已选定唯一应用模块。
- **操作流程：**
  1. **选定模块：** 提拆派计划或外仓收货计划，二选一。
  2. **配置条件：** 在该模块规则卡中添加判断条件；条件之间为并且。
  3. **保存：** 见 **4.3.5**。

规则区说明：满足以下 **全部** 条件时，自动打上此标记；不满足则取消。

**可判断的项**

| 应用模块 | 可判断项 | 取值方式 |
|----------|----------|----------|
| 提拆派计划 | 拖车供应商、自带车架 | 与业务页该下拉选项一致 |
| 外仓收货计划 | 提货方式、提货供应商 | 与业务页该下拉选项一致 |

**运算符与取值**

| 运算符 | 是否需要取值 | 取值控件 |
|--------|----------------|----------|
| 为空、不为空 | 否 | 不出现取值 |
| 等于、不等于、包含、不包含 | 是 | 下拉，选项同对应业务页，不手输 |

**条件编辑约束**

- 新增一条条件时，业务项默认「请选择」。
- 同一模块内每个业务项只能用一次；已用项在下拉里置灰。
- 业务项用完后，「添加判断条件」置灰，不额外弹提示。
- 删除条件后，该项可再被选择；规则卡至少保留一行。
- 保存时：已选模块下须有至少一条已选业务项的有效条件；需要取值的运算符，取值不能为空。

#### 4.3.5 【配置】编辑标记

- **使用场景：** 修改已有标记后保存。
- **业务规则（核心）：**
  - 标记名称、显示优先级、文字颜色、背景颜色、标记类型、应用模块必填。
  - **历史单据不做处理。** 保存配置不会按新规则批量打上或摘掉已有计划上的标记。
  - **二次识别**仅在该计划 **创建**，或对该计划做 **状态变更、状态维护、时间维护、编辑计划** 时发生；此时按保存后的当前规则判断系统标记。

**类型切换二次确认（保存时）**

| 场景 | 标题 | 说明 |
|------|------|------|
| 系统标记改为手工标记 | 改为手工标记 | 已打上的此标记会保留，不会批量取消。之后系统不再自动打上或取消，只能人工处理。确认保存？ |
| 手工标记改为系统标记 | 改为系统标记 | 已打上的此标记会保留，不会批量改写。之后仅在计划创建或发生状态变更、状态维护、时间维护、编辑计划时，按新规则二次识别。确认保存？ |

  - 点取消则不保存。
  - 由启用改为停用时另确认：停用后不能再新打，系统不再二次识别；已打上的标记保留，不会批量清除。确认停用？

#### 4.3.6 【提拆派 / 外仓收货】列表、触发与详情

两页规则一致。

**多标记排序**

1. 按显示优先级：紧急 > 优先 > 普通。
2. 优先级相同：按标记名称排序。

**系统标记二次识别时机**

以下操作完成后，对该计划按当前启用的系统规则重新判断打上或取消：

| 操作 | 说明 |
|------|------|
| 创建计划 | 新建计划保存成功 |
| 状态变更 | 计划状态变更为目标状态 |
| 状态维护 | 状态相关信息维护保存 |
| 时间维护 | 时间相关信息维护保存 |
| 编辑计划 | 修改计划保存成功 |

配置页的新增 / 编辑 / 停用不触发历史单二次识别。

**手工打标**

- 列表工具栏「重点标记」：勾选计划行后，选择本模块已启用的手工标记打上或取消。
- 系统标记不出现在手工选择列表中。

**详情顶栏**

| 位置 | 调整后 |
|------|--------|
| 原「已标记」位置（标题旁） | 展示 **计划状态** |
| 原「状态」位置（右侧操作区） | 展示 **已打上的标记**（排序规则同上） |
| 状态（如已拆柜）后面的「重点标记」按钮 | **去掉**，详情顶栏不再放绑定标记入口 |

- 已打上的标记一律展示（含配置已停用的）；手工停用标记若该单已打上，仍可在列表入口取消。
- 标记不改变状态流转、不拦截保存。
- 该计划操作日志记录打上 / 取消：手工记操作人；系统二次识别记为系统，并带规则摘要。

- **异常处理：**
  - 未勾选计划行：提示先勾选再标记。
  - 未选择要打的手工标记：提示请选择。

#### 4.3.7 【配置】操作日志

采用通用字段变更记录。每条含：操作、变更明细、操作人、时间。按时间倒序。列表行「日志」查看。

| 操作 | 变更明细 |
|------|----------|
| 新增 | 记录保存时**全部**配置项。格式：配置项名：值 |
| 修改 | **只记录本次有变化的配置项**。格式：配置项名：旧值 → 新值。未改的不记 |

值为空时记「空」。

**本期纳入日志的配置项**

标记名称、显示优先级、文字颜色、背景颜色、备注说明、标记类型、应用模块、状态、自动规则。

只记配置本身，不展开「改到了哪几张计划单」。计划上的打上 / 取消记在该计划的操作日志。

## 5. 界面与交互需求

界面以现有原型为准。本章只补业务约束。

### 5.0 界面要点

**配置列表**

- 含类型、显示优先级、自动规则；不含文字颜色、背景颜色列。
- 自动规则多条件用「且」拼接。
- 行操作含编辑、日志，同一行且有间距。

**新增 / 编辑弹窗**

- 显示优先级默认普通。
- 选手工标记：应用模块为多选。
- 选系统标记：应用模块为单选，并展开对应模块的规则卡。

**提拆派 / 外仓收货详情顶栏**

- 状态与已打标记位置对调；去掉状态旁的绑定标记按钮。

### 5.1 页面布局规范

以原型为准。详情顶栏以 **4.3.6** 为准（若与旧原型不一致，按 4.3.6）。

### 5.2 交互反馈

| 场景 | 交互要求 |
|------|----------|
| 系统改手工后点保存 | 弹窗确认，文案见 **4.3.5**；取消则不保存 |
| 手工改系统后点保存 | 弹窗确认，文案见 **4.3.5**；取消则不保存 |
| 启用改为停用后点保存 | 弹窗确认，文案见 **4.3.5**；取消则不保存 |
| 规则中业务项已用完 | 「添加判断条件」不可点，不弹 toast |
| 保存校验不通过 | 提示必填项或规则不完整，留在弹窗内 |

## 6. 非功能性需求

### 6.1 性能需求

二次识别只针对当前正在保存的那一张计划，按启用中的系统标记逐条判断，不要求全库扫描。

### 6.2 安全需求

配置页与业务页打标按角色权限控制；无权限不展示入口。

### 6.3 兼容性需求

与员工端现有列表、详情、弹窗交互一致。

## 8. 上线与运维计划

- **数据初始化：** 将现网已使用的重点标记迁入配置；「未派拖车」等自动场景配为系统标记并启用规则。历史单不批量重算。
- **培训与支持：** 说明显示优先级只管展示；编辑配置不处理历史单；二次识别发生在创建计划及状态变更、状态维护、时间维护、编辑计划。
- **回滚策略：** 停用即可停止二次识别；已打标记保留。
