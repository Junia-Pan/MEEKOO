## 弹窗输入两列布局规范（适用于本项目 client-pages）

### 目标

- 任何“弹窗页面”（modal 内的表单），单行输入型字段尽量做到“一行显示两个字段”。
- 不改变页面整体风格，仅调整表单栅格列宽（col）。
- 页面内不出现“原型/模拟”等提示性文案（包含标题、字段说明、help 文案、toast 文案等）。

### 适用范围

- 使用 `_ui-kit.js` 的 `formGrid(fields, initial)` 生成表单的页面。

### 规则

#### 1）单行字段（两列/行）

- `type: "text" | "number" | "date" | "select" | "file"` 这类“单行字段”，统一设置 `col: 6`
- 若不写 `col`，`formGrid` 默认也是 `col-6`（两列/行），但建议显式写出，避免以后默认值变更。

#### 2）多行字段（独占一行）

- `type: "textarea"` 统一设置 `col: 12`
- 多行描述/备注/说明等内容应独占一行，体验更好。

#### 3）按业务需要可独占一行的字段

- 文件上传通常可设置 `col: 12`（更清晰），也可 `col: 6`（追求紧凑）——以页面实际布局为准。

#### 4）文案规范（去“原型/模拟”）

- 弹窗标题、按钮文案、字段 help/placeholder 等，不使用“（原型）”“（模拟）”“模拟保存/模拟提交”等字眼。
- 若某功能暂未接真实接口，也不要在界面提示“模拟”，仅保持正常产品文案。
- 不新增“功能清单 / 后续可补 / 规则说明 / 流程图说明”等面向开发的说明性话术到页面/弹窗中（包含 `.note` 区块、help 文案、toast 文案等）。

##### 4.1）弹窗标题规范（标题 = 触发按钮文案）

- 任何由按钮触发的弹窗（modal），其 `title` 必须与触发按钮的文案 **完全一致**。
- 弹窗标题不拼接业务编号/计划号等动态信息（如 `（${row.id}）`）；需要展示编号时放到弹窗内容区（如基础信息里展示“计划号”）。

**例外（目标性操作允许带编号）**

- 若按钮属于“目标性操作”，标题允许（建议）带上目标编号以便用户确认操作对象，例如：`修改计划（${row.id}）`、`上传文件（${row.id}）`。

#### 5）按钮区规范（统一右对齐）

- 弹窗底部按钮区（`.modal-foot`）统一 **右对齐**（默认样式 `justify-content:flex-end`）。
- 不在单个页面/弹窗里把按钮改成左对齐；若需要增加额外操作按钮（如“回复”），也应与“关闭/确认”放在同一组并保持右对齐。

#### 6）placeholder 规范（统一“请输入xxx”）

- 查询/表单输入框的提示语统一使用：`请输入{字段名}`（字段名与 label 保持一致）。
- 避免使用“例如：xxx”作为 placeholder；示例值如有必要可放在 help 文案或字段旁说明。

##### 6.1）查询条件 placeholder 规范（统一为空）

- 查询条件输入框（筛选区）如果上方已经有字段标题（label），则 placeholder 统一留空（不展示任何提示语）
- 例外：日期选择框使用 `yyyy/mm/dd` 的视觉提示层（见“日期选择框提示语规范”）

##### 6.2）导入弹窗规范（模板下载入口）

- 任何带“导入”能力的弹窗，需提供“下载模板”入口（按钮或链接），让用户可直接获取模板文件。
- 模板下载不出现说明性话术（如“原型/模拟/功能清单/规则/后续可补”等），仅保留必要的业务文案。
- 导入弹窗视觉风格统一按以下结构（参考：提拆派计划-导入计划）：
  - 顶部：左侧“导入模板”文本，右侧主按钮“下载模板”
  - 中部：虚线边框拖拽区（Excel 图标 + 文案“点击或拖拽 Excel 文件到此区域”）
  - 底部：文件条（“选择文件”按钮 + 文件名，默认“未选择文件”）
  - 交互：支持点击拖拽区触发选择文件；支持拖拽文件到区域；未选择文件时点击“开始导入”需提示并阻止提交

#### 7）空值展示规范（统一用“-”）

- 所有“空白字段/无数据”的展示统一使用半角连字符：`-`
- 不使用长破折号 `—` 作为空值占位（视觉过粗）
- 推荐写法：`value || "-"` 或 `value || el("span",{class:"muted"},"-")`

##### 7.1）表格单元格对齐规范（左对齐 + 垂直居中）

- 所有列表/明细表格（含 `.table`、`.excel-table`）的 `th/td` 统一：
  - 水平：**左对齐**（`text-align:left`）
  - 垂直：**居中**（`vertical-align:middle`）
  - 内边距：左右上下统一 **10px**（表格里用 `padding:10px`，不要用 margin）
- 若单元格内有按钮/入口（如“预约文件”胶囊按钮/下载按钮），需留出与边框的安全距离，避免贴边（例如 `margin:2px 8px` 或等效 spacing），参考“创建计划-货件信息”里的上传/入口按钮间距。
- **文件上传控件**：须符合「点击或拖拽」规范（见 `前端页面规范.md` →「文件上传（拖拽 + 点击）」），不要只用原生 file 空控件。

### 例子（推荐写法）

```js
fields = [
  { name:"a", label:"字段A", type:"text", col:6, required:true },
  { name:"b", label:"字段B", type:"text", col:6 },
  { name:"c", label:"详细描述", type:"textarea", col:12, rows:4 },
  { name:"d", label:"附件上传", type:"file", col:12 },
]
```

如果需要支持多选上传：

- `controls.files.setAttribute("multiple","")`

### 禁止项（避免破坏风格与文案一致性）

- 不在弹窗里新增自定义表格皮肤/表头颜色/额外边框等“全局视觉风格变更”。
- 只在字段 `col` 与必要的输入属性（如 `multiple`/`accept`）上做调整。
- 不新增任何“原型/模拟”提示文案（包含 help 文案）。
